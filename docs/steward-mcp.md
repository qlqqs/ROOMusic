# 用 MCP 客户端连接 ROOMusic

ROOMusic 在 `/api/v1/mcp` 提供 MCP 服务，Claude Code 等客户端可以用个人访问令牌连上来，以令牌所属用户的身份调用工具。
目前提供的都是只读工具（查看曲库、扫描与操作记录）。

## 取得令牌

登录后打开“设置 › 访问令牌”，新建一个令牌：

- 权限选“只读”即可使用现有的全部工具。“读写”令牌以后可以执行修改操作，修改直接生效，ROOMusic 不会再确认，
  由客户端自己的权限提示把关。
- 令牌明文只在创建时显示一次，之后只能看到末四位；丢了就吊销重建。
- 每人最多 20 个未吊销的令牌。

管理员关闭“成员使用管家”后，成员的令牌暂时不能用，重新打开后恢复。成员被停用后，其令牌同时失效。

## 接入 Claude Code

```bash
claude mcp add --transport http roomusic <实例地址>/api/v1/mcp --header "Authorization: Bearer <令牌>"
```

创建令牌后的对话框里有填好地址和令牌的完整命令。

## 排查

| 现象 | 原因 |
| --- | --- |
| 客户端报连接失败（401） | 令牌写错、已过期、已吊销，或账号被停用 |
| 403 | 管理员关闭了成员使用管家；或请求带了不受信任的 `Origin` |
| 429 | 同一来源地址一分钟内认证失败达到 30 次，暂停一分钟。实例前面有反向代理时，所有客户端共用一个来源地址 |

服务端在暂停开始时记一条 `steward.mcp.auth.throttled` 日志，每次工具调用记一条 `steward.mcp.tool.finished`。
