# 用 Subsonic 客户端连接 ROOMusic

ROOMusic 在 `/rest` 提供 OpenSubsonic 兼容接口。Symfonium、Feishin、Amperfy、DSub、Ultrasonic 等支持 Subsonic 的手机和桌面客户端，
可以用 ROOMusic 的用户名和登录密码连上来：浏览、搜索、在客户端本机播放、收藏、评分、歌单、歌词和听歌记录都与网页端互通。
支持点唱机模式的客户端还能当遥控器，让家里的播放区出声。

## 开启与关闭

接口默认开启。管理员在“设置 › 第三方客户端”里控制“允许第三方客户端连接”：

- 客户端常用令牌方式登录（只发送密码加盐后的哈希），服务器要能还原密码才能核对，所以开启期间会用实例密钥加密保存每位成员的一份登录密码。
- 关闭后所有客户端立即无法连接，保存的密码副本全部删除。以后再开启，成员要重新登录一次网页或在账号页确认一次密码。

## 连接

每位成员在“设置 › 账号 › 第三方客户端”里查看要填写的内容，旁边都有复制按钮：

| 客户端里的项目 | 填写 |
| --- | --- |
| 服务器地址 | ROOMusic 的网址，例如 `http://192.168.1.10:8090/`；从外网访问时填反向代理后的地址 |
| 用户名 | ROOMusic 的用户名 |
| 密码 | ROOMusic 的登录密码 |

“密码”一行显示“已就绪”时可以直接连接。显示“确认密码”按钮时，先点它输入一次登录密码：接口开启之前就有的账号，
以及管理员用命令行重置过密码的账号，服务器里还没有密码副本，令牌方式登录会失败。在网页上重新登录一次也有同样效果。

在网页上修改密码、管理员在网页上重置密码后，副本会自动换成新密码，客户端改填新密码即可。

## 能用的功能

| 功能 | 说明 |
| --- | --- |
| 浏览与搜索 | 艺人、专辑、歌曲、流派、随机歌曲；专辑列表支持按名称、艺人、年份、流派、最新、随机、收藏、最近播放、最常播放、最高评分排序 |
| 封面 | 专辑封面与艺人图片，按客户端请求的尺寸缩放 |
| 播放与下载 | 见下一节 |
| 收藏与评分 | 曲目、专辑和艺人的收藏，1–5 星评分；与网页端是同一份数据 |
| 歌单 | 只能看到和修改自己的歌单；客户端里的“公开”和备注会被忽略，歌单始终私有 |
| 歌词 | 支持结构化歌词的客户端可以逐行同步显示，来源与网页端相同 |
| 听歌记录 | 客户端提交的播放计入网页端的播放历史；“正在播放”对所有成员可见 |
| 点唱机 | 见后文 |

客户端里的“专辑”对应 ROOMusic 的一张专辑，曲目取它的默认版本，不在客户端里选版本。全部音乐显示在一个名为“ROOMusic”的音乐文件夹里。

## 播放与音效

每个客户端第一次连接时会登记成一台设备，名称就是客户端报告的名字。它的播放设置在网页端“设置 › 播放”顶部的“设置的设备”里选到，
可以和其他设备一样单独设均衡、卷积等音效，也可以删除；删除后客户端下次连接会重新登记，设置恢复为默认。

| 情况 | 客户端收到的音频 |
| --- | --- |
| 默认：没有设置任何音效，源文件是 FLAC、MP3、AAC、Ogg Vorbis、Opus 或 WAV | 原文件，可以拖动进度 |
| 源文件是 ALAC、APE、DSD（DSF/DFF）或 CUE 分轨，或者这台设备设置了音效 | 服务器处理后输出 FLAC |
| 客户端把码率限制在源文件以下，或这台设备的音质设成有损（客户端没有指定格式时） | 服务器处理后输出 Opus |
| 客户端指定了 MP3、Opus、AAC 或 FLAC | 按指定格式输出 |
| 下载 | 始终是原文件；CUE 分轨转成 FLAC |

服务器处理过的音频不能按字节拖动，客户端会从新的位置重新请求。同时处理的曲目数有上限，满了时客户端会收到“服务器忙”。

## 点唱机

支持点唱机模式的客户端（DSub、Ultrasonic、Symfonium 等）打开点唱机后，播放列表、播放暂停、切歌、跳转和音量都作用于 ROOMusic 的一个播放区，
声音从那个播放区的设备出来，编组同步和音效照常生效；网页端会实时看到同样的队列和状态。

控制哪个播放区在“设置 › 账号 › 第三方客户端 › 点唱机控制”里选。默认是“最近播放过的播放区”。
控制局域网设备时，本人的网页登录要仍然有效（浏览器可以关着）。

## 不支持

- 按文件夹浏览：依赖文件夹视图的客户端模式里看不到内容，请切换到按艺人或专辑浏览。
- 播客、网络电台、分享链接、跨设备同步播放队列、用户管理接口，以及 OpenSubsonic 的 API 密钥登录。

## 排查

| 现象 | 原因 |
| --- | --- |
| 客户端报用户名或密码错误 | 密码填错；账号页“密码”一行还没有就绪，先确认一次密码；账号被停用；管理员关闭了接口；或失败次数过多被暂停 |
| 明文密码能连，令牌方式连不上 | 服务器里还没有密码副本，在账号页确认一次密码 |
| 文件夹视图是空的 | 不支持按文件夹浏览，见上一节 |
| 点唱机报“没有可控制的播放区” | 还没有可以控制的播放区：先在网页上播放一次，或在账号页选定播放区 |
| 播放报“服务器忙” | 同时处理的曲目太多，稍后重试；不需要音效的设备保持默认设置，可以直接发原文件 |

客户端和网页登录共用失败次数限制。实例前面有反向代理时，所有经代理的客户端共用一个来源地址，一台客户端反复输错密码会暂时挡住其他人的登录。
反向代理只需要把 `/rest/` 原样转发给 ROOMusic，其余要求见[部署说明](../deploy/production/README.md)的“反向代理”一节。
