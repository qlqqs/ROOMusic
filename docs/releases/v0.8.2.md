本版新增 Subsonic/OpenSubsonic 兼容接口、Squeezelite 播放器与多房间同步编组，以及个人评分。

## 新功能

- **Subsonic 客户端**：Symfonium、Feishin 等 Subsonic/OpenSubsonic 客户端可以用 ROOMusic 的账号连接，地址就是 ROOMusic 的网址。支持浏览、搜索、封面、播放与下载、收藏、私有歌单、歌词、评分和听歌记录；点唱机模式可以控制在账号页选定的播放区。管理员可以在设置里整体关闭。设置方法见[用 Subsonic 客户端连接](https://github.com/qlqqs/ROOMusic/blob/main/docs/subsonic-clients.md)。
- **Squeezelite 播放器（SlimProto）**：在“设置 › 局域网设备”打开 SlimProto 后，piCorePlayer、moOde 等系统里的 Squeezelite 会自动连上来，以原采样率无损播放，最高 768 kHz。USB 解码器插在服务器上时，可以用附带的 Compose 文件在旁边运行一个 Squeezelite 容器。
- **播放区编组**：多台 Squeezelite 可以编成一组同步播放，服务器逐帧补偿各台的时钟漂移，偏差约 1 ms 内；编组面板里可以调组音量和各成员音量。
- **个人评分**：网页端可以给曲目和专辑打星，“我的评分”页列出全部评分；评分在重新扫描、专辑合并后会跟着转移，管家也能读写评分。
- **第三方客户端的播放设置**：每个 Subsonic 客户端作为一台设备出现在“设置 › 播放”顶部的下拉里，可以单独设均衡等音效，也可以删除。

## 改进

- 宽屏加了顶栏，头像移到右上角，管家改为浮起的卡片；列表筛选收进放大镜按钮，与顶栏搜索区分开。
- 专辑列表加了“全部”选项，与“需要关注”成对切换。
- 管家新会话的默认模式可以在个人设置里指定。
- 重做了“设置 › 关于”，问题反馈会带上诊断信息。
- 界面走查：去掉重复和无意义的显示，设置里的输入框与按钮回到同一行，外部源的说明和密钥行更清楚。

## 修复

- 网卡变化后设备发现与 PTP 对时会重建；PTP 取往返最短的样本；mDNS 定向查询改用单播。
- 托管输出在锁外等待收尾，订阅关闭后会重新订阅；AirPlay 心跳容忍偶发超时。
- 高采样率起播门槛不再超过默认输出缓冲，兼容 1479 之前版本的 Squeezelite。
- 修正窄屏多出一条顶栏的问题。

## 升级注意

- 启动时自动执行数据库迁移 0078–0085（SlimProto 设备、播放区编组、个人评分、Subsonic 等），无需手动操作。
- Subsonic 接口升级后默认开启。Subsonic 客户端需要服务器保存一份加密的登录密码，已有账号要先在网页上重新登录一次，或在账号页确认一次密码，之后才能用客户端连接。不需要时由管理员在设置里关闭，关闭会同时删除所有已保存的副本。
- 使用 SlimProto 时，宿主机防火墙需要向局域网放行 TCP 和 UDP 3483；同机已经运行 Lyrion Music Server 时端口会被占用，停掉它后自动恢复。详见部署说明的“局域网设备所需入站端口”。
