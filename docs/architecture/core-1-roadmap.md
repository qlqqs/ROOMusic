## M7 外部数据源与自动整理

2026-11-22 立项（选择者 qlqq，决定 U1–U12，全文见 [ADR 0006](adr/0006-auto-curation-and-sources.md)）。父任务 `11-22-auto-curation-sources`，
父任务本身不实施代码；每个子任务单独规划、实施、验收和归档，只为下一个获批的独立交付创建任务。

目标：接入外部音乐数据源，并让曲库整理默认自动进行——程序处理能保证正确的事，模型对程序拿不准的做兜底判断，
人只处理模型也判断不了的例外；所有自动修改可撤销。这取代了“外部产出只作为候选、等人确认”的原则，
也取代了 R1 对 Release 合并与拆分的搁置。弱相似不得合并、音乐文件只读、后端是唯一权威这三条不变。

## 静态审查发现的现有风险

`internal/library/httpapi/root_operations.go` 的停用/恢复指纹原先没有包含路由 root ID，重放查询只按 actor、操作类型
和幂等键查记录；同键同 body 用于不同目录时会返回前一个目标的结果。已记录于
[ADR 0003](adr/0003-governed-operations.md)与运行合同技术债，**2026-09-29 由 F2 动态复现并修复**：
指纹含目标，同键请求串行，旧记录不做兼容。修复没有与纯拆包混合，也没有等通用操作平台。
