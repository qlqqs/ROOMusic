# ROOMusic 前端设计锚（DESIGN.md）

> 唯一设计锚。任何前端视觉改动先对照本文件；本文件与实现冲突时以本文件为准并同步修正实现。
> 方向来源：2026-09-04 四方向预览（`design-previews/2026-09-04-roomusic-frontend/`），
> 用户选定「A · 唱片店月刊」+ 混入 C 的圆润 + 更复古。

## 产品与受众

自托管音乐库管家，面向个人、家庭与小型私有群体的大容量 NAS 收藏。
界面是工作台：浏览、检索、整理、连续播放，不是营销页。

## 功能契约

- 3 秒内必须能回答：库里有什么、扫描/同步是否正常。
- 必须能完成：搜索发行版本、浏览封面网格/列表、打开发行详情（Medium/Track）、加入演示播放队列、看到底部播放条。
- 管理操作（用户、目录、扫描）必须有 pending、冲突、失败与恢复路径。

## 目标情绪

像一本保养得很好的独立唱片店店刊：纸张、墨色、朱红批注。
被策展的收藏感，而不是数据库后台；温暖、笃定、可久用。

## 灵感转译（供体 DNA）

取自 `claude`（Anthropic）设计系统，只取以下 5 条，不复制其品牌外观：

1. 羊皮纸画布：页面底色用暖纸色而非白或灰。
2. 全暖中性色：所有灰都带黄棕底色，禁止冷蓝灰。
3. 衬线负责权威、无衬线负责功能：标题用衬线单字重，控件与正文用系统无衬线。
4. 赤陶/朱红作为唯一强 accent，刻意"不科技"。
5. 正文行高 1.6 上下的阅读节奏；阴影以 ring（细描边式）为主，不用厚重投影。

圆润基因取自方向 C：封面、胶囊控件与悬浮播放条使用大圆角。

## 色彩角色

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 纸底 `--paper` | `#f1ead8` | 页面底色，陈纸感 |
| 纸面 `--paper-raised` | `#f8f3e6` | 卡片、输入、控件等抬升面 |
| 纸凹 `--paper-sunken` | `#eae1ca` | 输入框、骨架屏基底 |
| 墨色 `--ink` | `#29241a` | 主文字、播放条胶囊 |
| 墨软 `--ink-soft` | `#57503c` | 次要文字 |
| 墨淡 `--ink-faint` | `#6f6650` | 元信息、占位 |
| 线 `--line` | `#d9cfb4` | 常规分隔 |
| 粗线 `--line-strong` | `#c2b48f` | 双线刊头、强调分隔 |
| 朱红 `--accent` | `#b23a2a` | 唯一强 accent：激活、主按钮、焦点、印章 |
| 朱红墨 `--accent-ink` | `#f8f3e6` | 朱红底上的文字 |
| 橄榄 `--ok` | `#6d7a3f` | 同步正常等正向状态 |
| 蜜蜡 `--warn` | `#8a5d15` | 演示模式、需要检查、扫描未完成 |

对比度纪律：正文与控件文字相对所在底色满足 WCAG AA；`--warn` 只用于纸底上的文字/描边，不做小字底色。

## 排版

- 标题与品牌：衬线栈 `Georgia, "Noto Serif SC", "Songti SC", "STSong", serif`，单一字重（600），行高 1.1–1.3。
- 正文与控件：系统中文无衬线栈，正文行高约 1.6。
- 眉批（eyebrow）：无衬线小号 + 加宽字距 + 全大写拉丁/中文，墨色淡。
- 禁用斜体；强调用字重、颜色或字号。
- 数字与进度使用 `font-variant-numeric: tabular-nums`。

## 组件语言

- 双线与发丝线：顶栏用 `3px double` 印刷规则线；列表与区块用 1px 发丝线。
- 封面：墨底 + 纸色衬线首字 + 内嵌同心圆纹（黑胶封套暗示）；真实封面图直接铺满。
- 圆角：封面/卡片/详情内页 14–22px；胶囊控件（筛选、视图切换、详情操作）999px；数据行与小输入框 6–8px。
- 激活态：导航为纸面底 + 朱红左侧"书脊"条；胶囊切换为朱红底 + 纸色字。
- 播放条：底部悬浮墨色胶囊（离边 12–16px，圆角 20px，暖色薄投影），朱红圆形播放键——签名组件；无侧边栏后左右对称离边。
- 焦点：`focus-visible` 统一 2px 朱红外描边，offset 2px。
- 骨架屏：纸凹底暖色 shimmer，不用冷灰。

## 布局（头版式信息架构，2026-09-05 起取代三栏工作台）

- 通栏报刊刊头：期号行（卷号 / 同步状态 / 用户）+ 居中超大衬线刊名 + 期旨行，上下双细线收口；不使用侧边栏。
- 栏目行：水平编号导航（01 首页 / 02 专辑库 / 03 编辑部），为真正的页面切换——轻量 hash 路由（`#/`、`#/library`、`#/settings`），当前页朱红下划线 + `aria-current`；不引入 router 依赖，Go 同源服务无需 SPA fallback。节目单归属首页；编辑部仅管理员可见，非管理员访问 `#/settings` 显示提示。
- 头版头条（仅在未筛选第 1 页出现）：完整横幅卡片——大封面 + 朱红「头条」印章 / 衬线大标题、播放操作与档案卡 / 右栏内联完整曲目表（碟片可折叠，目录式点线）。横幅桌面收窄定高（宽 95%、高 440px，居中，随窗口动态调整），曲目栏随横幅高度内部滚动；≤1024px 恢复自然高度、曲目栏限高 320px。档案信息为内联元信息行，按字段内容长度自适应、斜杠分隔（如 2024 / 1 碟 / 18 首 / 厂牌）。summary 先渲染、详情异步补齐（骨架占位），不提供「翻开内页」入口；点下方唱片架更换头条并平滑滚回顶部，切换时折叠态重置。
- 「新入架」唱片架：单行横向滚动，大封面（190px），当前头条带朱红描边；右侧「查看更多 →」锚点跳转专辑库（入库总目）。只有专辑库网格/列表里的发行点击才翻开杂志内页。
- 「入库总目」为完整目录区（搜索、筛选、视图切换、分页齐全）；「节目单」为通栏横向节目带（编号 + 曲名，当前项朱红底划线）；「编辑部」收管理卡片。
- 详情为「翻开的内页」整页浮层：纸底圆角大页覆盖全屏（桌面四周离边 14px），不使用侧滑抽屉；顶部有吸顶双线页眉与「合回本刊」关闭钮；内页左右跨页构图——左栏封面 + 档案卡，右栏标题、操作与目录式曲目表（点线分隔、衬线序号）。
- 移动端（≤768px）：刊头缩小、栏目行横向滚动、头条改单列、节目带保持横向滑动；播放条降为底贴边圆角条。
- 编辑式节奏来自：双线刊头、眉批期号感、区块间大留白；不做营销式 Hero。

## 深度与动效

- 深度只靠 ring 描边与一层暖色薄投影；禁大面积渐变与玻璃拟态。
- 动效克制：详情内页以 220ms 上浮淡入（幕布 180ms 淡入），骨架 shimmer；禁 `transition: all`、禁 `ease-in`、禁无目的长动画。
- 必须保留 `prefers-reduced-motion` 降级。

## Do / Don't

- Do：暖色-only、衬线标题、朱红单 accent、可见焦点、真实数据感文案。
- Don't：冷蓝灰、AI 紫蓝光晕、斜体、无语义卡片海、居中 Hero 模板、装饰性 glow。

## 响应式验收

- 桌面 1440/900 宽度刊头与头版区块无重叠；`375px` 移动端上下堆叠可读；详情内页移动端全屏无圆角。
- 播放条固定定位不遮挡末尾内容（内容区按 has-player 预留底部空间）。
- 键盘可完成搜索、浏览、详情开关与播放控制，焦点可见。
