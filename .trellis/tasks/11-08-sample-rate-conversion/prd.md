# 采样率转换

父任务：[音频算法对标](../11-08-audio-dsp-reference-port/prd.md)。参考稿（本机 `~/.local/share/roomusic-reference/reference-design.md`） §6.2。算法默认照参考稿的参数和公式实现，只有确信同样好或更好时才偏离，并写明理由。所有算法只在后端（Go）实现（父任务 A1）。

## 需求

- **C1 策略**：五种策略，即 `none`（不转换，设备不支持时回退）、`max_sample_rate`（转到设备支持的最高采样率，≤768 kHz）、`power_of_2`（按 2 倍升频到设备上限）、`dsd`（转到 DSD 域，依赖 PCM→DSD 和支持 DSD 的输出端）、`custom`（用户指定目标）。设置归属播放区，默认 `none`；需要转换时默认用“精确 · 线性相位”滤波器（2026-11-08 用户裁决）。
- **C2 兼容性回退**：原采样率 → 换族（44.1×480/441 或 48×441/480）→ 减半到 44.1 kHz → 倍增到 768 kHz。命中回退时，信号路径标注“兼容性转换”，并降低质量评级。
- **C3 滤波器核**：76 组核（6 族：线性/最小相位 × smooth/precise/2s；倍率含 2/3/4/6/8/16/32/64 倍、3/2、160/147、320/147、640/147、1280/147、147/20、147/40、147/80），每相抽头 smooth 20、precise 166、2s 19，总长 `上采样倍数 × 每相抽头 + 1`，直流增益 1，群延迟 smooth 10、precise 83、2s 9.5 个输入样本。**系数由我们用公开方法自己生成**（smooth、precise 用 Kaiser 窗 sinc 运行时生成，2s 用线性规划离线生成后入库，最小相位一律经倒谱变换得到），达到 §6.2 的指标：precise 过渡带约 1.5%×截止、通带波动 <0.01 dB、阻带 >180 dB；smooth 过渡带约 54%、通带下垂约 2.4 dB；2s 截止约 0.48×Nyquist；2 倍 smooth 为半带（中心抽头 0.5）。生成器进仓库（见 [design.md](./design.md) §2）。
- **C3a 对照**：附录 F 与 `~/.local/share/roomusic-reference/roomusic-src-kernels.csv`（参考稿配套的 76 组全量系数，SHA-256 `22fb34a3fdb781c5a71b1bc7ba5ce0207475f984e2f8b2f00c1af4b015612150`）只在本机做对照：逐组比较频响（通带、过渡带、阻带）、直流增益与群延迟，不进仓库、不进镜像、不作为测试依赖。
- **C3b 降频**：参考的核都是升频（外加 3/2），48→44.1、减半等降频用同一原型滤波器做抽取器（L/M 转换的原型截止在 π/max(L,M)，升降两个方向可以共用），设计里写明增益归一方式。
- **C4 处理块与延迟**：处理块 = 输入采样率 / 5（200 ms）；线性相位核的固有延迟为 `抽头数/2/最小公倍数`，最小相位核记 0。
- **C5 使用方**：卷积 IR 重采样（linear/precise）、DSD 降采样到 352.8 kHz、渲染流按输出端能力做兼容性转换（同时替换第一批由 ffmpeg 临时完成的有损档 48 kHz 与超上限降频，父设计 §6）、以后的 DAC 输出。

## 验收

- 每种核实测通带波动、过渡带、阻带衰减满足 C3 的指标；本机对照时每组核的阻带、通带与群延迟都不劣于参考核（只允许数值误差，判定口径见 design.md §8；只在本机跑，不进 CI）。
- 44.1→48、48→44.1、2 倍、4 倍等常见转换下，扫频信号经转换后频率正确，带内电平误差在指标内。
- 输出端声明不支持源采样率时，按 C2 的顺序回退，信号路径显示兼容性转换。
