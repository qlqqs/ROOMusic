# 艺人页与来源设置的图标化界面

父任务 `11-24-artist-web-search`（R1–R9、D5）。设计稿：`research/mockup.html`（可交互；左上切换视角与状态）。
主代理实现；分两段，分别落在两个后端子任务的分支上（后端字段一合入就有前端解码，`main` 不出现解码失败）。

## 需求

- U1 来源印章：艺人页大圆章右下 45° 处一枚印章，图标表示图片来源——书本（有许可来源）、拼图（插件）、星光（网络搜索，强调色）、人加笔（管理员提供）。没有图片时不显示（管理员视角下网络搜索中或待确认时显示地球）。
- U2 来源弹层：点印章弹出来源、作者、许可、原网页（网络搜索列出引用网页），每行前是图标，外链在新窗口打开。管理员在弹层底部有三个图标按钮：标记不对、指定对应、更换图片。Esc、点外部关闭，焦点回到印章。
- U3 简介：正文最多 3 行折叠；下方一行只有图标：来源图标（同 U2 的弹层，内容为简介来源）、展开箭头；管理员悬停或聚焦时浮出编辑与标记不对。原来的“简介：… / 图片：…”文字署名行去掉。
- U4 更换图片：管理员悬停圆章出现半透明遮罩与“加图片”图标，点击选文件；也可把图片拖到圆章上（金色虚线圈提示）。上传中圆章显示进度弧，完成后淡入新图。失败用文字提示原因（格式、大小）。
- U5 指定对应：弹层切换为输入框（链接图标前缀，占位“MusicBrainz / Wikidata”）；管理员在艺人页任意位置粘贴可识别的链接也直接弹出。识别后先显示骨架，再显示名字、简介短语、条目号与“名字一致”标记，点勾确认。名字不一致时勾按钮旁显示警示图标与提示，仍可确认。
- U6 标记不对与撤回：资料立即淡出，底部浮出深色胶囊（旗子 + 图片或简介图标 + 带 6 秒倒计时环的撤回按钮）。6 秒内撤回则不提交；超时、离开页面或再次操作时提交（`fetch` 的 `keepalive`）。读屏通过 `role="status"` 读出完整文字。
- U7 网络搜索状态（管理员）：处理中时圆章外一圈缓慢转动的细弧（`prefers-reduced-motion` 下静止）；待确认时印章为强调色底加地球并带提示点，弹层列出候选（名字、条目号、引用数），每个候选一个勾，底部一个叉表示都不是。采纳后圆章先显示进度弧，再淡入新资料。
- U8 简介编辑：原地变为文本框，右下码点计数 `n / 4000`，勾保存、叉取消，Esc 取消，⌘/Ctrl+Enter 保存。语言按是否含汉字自动判断。
- U9 角色标签：页头去掉“专辑艺人”“曲目艺人”；其余角色（作词、作曲、编曲、指挥、演奏、制作人）保留为可点的胶囊，跳到下方对应角色的曲目区。只有专辑艺人或曲目艺人角色时不显示标签行。
- U10 设置 › 自动整理 › 来源：新增一行“网络搜索”（地球图标），右侧两个依赖图标（星光 = 对话模型，放大镜 = 搜索来源）；就绪的图标正常显示，缺失的变淡并带警示点，悬停提示缺什么，点击前往管家设置；缺失时开关不可用。
- U11 例外列表认得艺人候选（目标列显示艺人名、链接到艺人页）。
- U12 普通账号只看到印章与来源弹层，没有任何操作入口。
- U13 解码：艺人图片与简介的来源接受 `manual`、`web_search`、`plugin:*`；`citations`、`links`、可空 `source_url`。

## 验收

- V1 设计稿的六种状态与两种视角在真实页面都能复现；390 与 1440 两种宽度截图无溢出（中文字体核对）。
- V2 所有图标按钮有 `aria-label` 与提示；键盘可达；焦点环可见；弹层焦点管理正确。
- V3 `prefers-reduced-motion` 下无转动与位移动画。
- V4 vitest 覆盖解码、印章、弹层、撤回计时、粘贴识别、简介编辑、角色标签；Playwright 覆盖管理员与普通账号两条流程。
- V5 `frontend/DESIGN.md` 与组件文档同步：图标化来源与“错误仍用文字”的约定。
