# 完善音乐客户端前端体验

## 目标

沿用复古唱片店视觉，完善导航、个人音乐库、歌单与模拟播放闭环，允许本地占位数据

## 已确认事实

- 用户已授权创建任务并进入规划；最终实施方案尚未审阅。
- `frontend/DESIGN.md` 已记录用户选择的唱片店月刊风格，本次沿用并打磨。
- `frontend/src/main.tsx:94` 使用 hash 页面路由，已有首页、专辑库、编辑部及真实认证与管理 API。
- `frontend/src/features/catalog/model/display.ts:163` 批量播放目前采用追加语义，需要区分立即播放与加入队列。

## 需求与验收

- R1 导航：保留现有页面，新增“我的音乐”，包含喜欢的歌曲、最近播放和歌单；个人列表支持按曲名、歌手筛选，浏览器返回可恢复页面。
- R2 收藏与历史：曲目行和播放器支持喜欢/取消喜欢；实际开始模拟播放时记录历史，去重并限制数量；各入口同步。
- R3 歌单：创建、重命名、删除、添加/移除歌曲、播放全部；处理空名称、空歌单和重复歌曲；删除须确认或可撤销。
- R4 播放：立即播放、下一首播放、加入队列语义明确；支持暂停、前后切歌、进度拖动、音量、静音、顺序/列表循环/单曲循环及随机播放。模拟时钟在曲末正确切换，明确标记模拟状态。
- R5 队列与歌词：任意页面可打开队列、播放指定项、移除任意项、调整顺序、清空；歌词可打开关闭，无歌词显示空状态。
- R6 保存：收藏、歌单、历史和播放偏好刷新保留，队列恢复后暂停；按用户身份隔离；损坏或不可用存储不导致崩溃。
- R7 视觉：沿用复古报刊结构，提升常用操作发现性；375px、900px、1440px 均无遮挡，固定播放器不遮住页面末尾；图标有名称和提示，浮层支持键盘关闭与焦点恢复。
- R8 演示：提供显式演示入口、有限曲目和本地封面，无后端也能完成上述流程；真实 API 错误不能静默替换成演示成功。

验收主路径：进入专辑或演示曲目 → 播放 → 喜欢 → 加入新建歌单 → 进入歌单播放 → 调整队列 → 刷新恢复。加入队列不打断当前项；移除当前项、末曲结束及清空后无越界状态。真实登录、搜索、详情及管理员操作维持现有合同，演示模式不发送管理写请求。

## 范围外与限制

不实现真实音频传输、下载、云端同步、推荐算法、歌词服务或后端新接口。音量只保存模拟控制状态。本地数据限当前浏览器，清理浏览器数据会丢失。真实曲目时长缺失时禁用拖动和自动结束，演示曲目提供时长。

- 状态：最终方案已获批准，进入实施。
