# 本地辅助

父任务：`.trellis/tasks/11-26-curation-chain-review`。每条决定的现状、依据和代码位置见父任务 `prd.md` 的对应段落（下表“出处”一栏）；规则汇总见 `docs/architecture/adr/0009-curation-chain-review.md`。

本任务只实现下面列出的决定，不改其他段的行为。实施中发现某条决定做不到或需要改，先停下报告，由主代理回父任务问用户。

## 目标

按父任务 B1 的决定：扫描规则定不了的，交模型按本地内容判断，交回的内容由程序核对后写入。

## 范围

| 事项 | 出处 | 要做的 |
| --- | --- | --- |
| 交给它的情况 | B1 表第 1 行 | 七类：只有文件名、没有标签；旧编码几种读法；艺人名里的 `&`、逗号是不是几个人；同目录几个专辑名且曲号不连续；认不出的碟目录名；缺碟号、缺曲号；专辑名里混着艺人名。另有两处接进来：A2.1 名字只有一半的，先补全再查；A2.5 拼不出来的署名，交这里拆 |
| 模型看到什么 | B1 表最后一行 | 这张专辑或这个目录的完整本地内容：标签、几种读法、注释、文件名、目录名；不查外部、不联网 |
| 交回四种 | B1 表第 2 行 | 文字：和本地原文等价，在 `textnorm.Text` 的基础上把下划线、点号、连字符等标点当空格，不能多出本地没有的字；编码：只能从候选编码里选一种，字由程序按它解；拆名字：拆出的几段按原顺序加原来的连接符，拼回去和原文一模一样；归组：哪些文件是一张、第几碟、第几首，每个文件只出现一次，同一张碟里曲号不重复。现有核对见 `backend/internal/curation/local_submit.go:67-175` |
| 模型归组记录 | B1 表 | 存成单独一条“模型归组”记录，下次归组时生效；用户手动合并、拆分过的不动；可撤销 |
| 写进去的算什么 | B1 表 | 标为推断，放在自动层最低一级；MusicBrainz 对上时由它的数据替换；可撤销；不审查 |
| 模型凭知识写的 | B1 表 | 不写入。程序认不出时，由识别判断（子任务 9）给线索，本任务不另建通道 |
| 什么时候做 | B1 表 | 需要本地辅助的专辑，先做本地辅助，再查 MusicBrainz；没配模型就跳过 |
| 规则版本 | A4 | `LocalRuleVersion` 只管本地辅助，升一次 |
| 一个模型 | B1 表 | 不单独配模型 |
| 规范 | 文档 | 整理合同里改到的段落 |
