# 管家 C1：ADR 0005 数据外发、提示注入、出站请求、密钥与令牌

父任务：`.trellis/tasks/11-15-music-steward-m6`（R13、R14；路线图 M6 行要求的 ADR）。

## 目标

写出并由用户批准 `docs/architecture/adr/0005-steward-data-and-egress.md`，规定四件事：
发给模型和外部服务的数据范围、不可信文本的处理、服务端出站请求的边界、密钥与令牌的存放。
C2 及之后的子任务按它实现。本任务只产出文档，不改代码、迁移和部署文件。

## 已确认的事实

- 服务端目前没有任何出站 HTTP 请求（只有独立命令 `backend/cmd/opra-update` 用到 HTTP 客户端）；
  管家是第一个让服务端主动连外部地址的功能。
- 会话令牌只存哈希（`backend/internal/identity/login.go:83`，`sessions.token_hash`）；密码用 bcrypt。
  数据库里没有存放可还原的第三方密钥的先例。
- 备份是整库 `pg_dump --format=custom`（`backend/internal/backup/service.go:262`），不排除任何表；
  存进数据库的内容都会进备份文件。
- 配置全部来自环境变量（`backend/internal/platform/config/config.go`），其中没有实例级的加密密钥；
  有受管数据目录 `ROOMUSIC_DATA_DIR`。
- 日志是 stdout 的结构化 JSON，已有脱敏规则（`.trellis/spec/backend/logging-guidelines.md`）。
- 产品合同规定审查子代理拿到的是有界方案与可给 AI 看的证据投影，不含原始数据库行、密钥、音频字节和
  不受限的路径（`.trellis/spec/backend/agent-and-operation-guidelines.md`）。
- 父任务已定：端点与密钥按用户配置（S15）；三种模式所有用户可选，`operator` 不询问（S12）；
  支持本地模型（S3）；联网含搜索与网页抓取（S8）。

## 不需要用户再选、按现有做法定的内容

- 访问令牌只存哈希，明文只在签发时显示一次，做法与会话令牌一致。
- 密钥与令牌不进日志、操作记录、接口响应和导出的对话（R14）；接口只返回密钥末几位。
- 音频字节、封面图片、数据库连接串、其他用户的数据不发给模型。
