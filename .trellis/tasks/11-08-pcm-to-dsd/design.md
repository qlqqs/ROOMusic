## 0. 结论

- 纯包 `backend/internal/dsp/sdm`：四种调制器（5 阶、7 阶、Clans 5 阶、Clans 7 阶）共用一份转换代码，只换系数；输入 ×0.5 并钳到 ±0.5、1 比特量化、MSB 先打包、块长 = DSD 采样率/5 且为 8 的倍数、校验失败整块输出 `0x69`。
- **16 组系数自己设计**，离线生成器 `go generate` 产出 `coeffs_gen.go` 入库（生成过程含数值优化与稳定性仿真，固定下来便于审阅）。方法：
  - 零点：直流 1 个 + Legendre 多项式正根 × 22.05 kHz 处的共轭对（5 阶 2 对、7 阶 3 对），各倍率相同的赫兹位置；
  - 极点：以 Butterworth 高通原型（H∞ = 1.5）为初值，在“带外最大增益 H∞ ≤ h、冲激响应 ‖h‖₁ ≤ l”的约束下最小化 0–20 kHz 的带内噪声（§2.3）。标准阶固定 h = 1.5，在 l 网格上取带内噪声最低且稳定上限 ≥ 0.60 的一组；Clans 再以稳定性仿真为约束精修，稳定上限 ≥ 0.56，换更低的带内噪声（§2.4）；
  - 系数 a 解线性最小二乘得到，g 由零点直接算出。
- **验收按“不劣于参考”**（§6.2）：逐组带内 NTF 均方根 ≤ 参考 + 0.1 dB，带内 SNR ≥ 参考 − 0.1 dB，稳定上限 ≥ 参考且 ≥ 0.55，零点频率 ±0.5%。2026-11-08 本机原型的 16 组结果见 §3.6。
- **附加系数**：5 阶 2 项、7 阶 3 项（每对零点一项）。附录 G 的 7 阶每组只列了两项，分析表明少列了一项（§5.2），prd M2 的“另各有两项附加系数”对 7 阶按 3 项实现。
- 首版只做库与测试，不接输出（M5）。

## 1. 调制器结构

N 阶（N = 5 或 7）、状态 s₀ … s_{N−1}、前一个输出 y′ ∈ {+1, −1}、本样本输入 x：

```text
d₀ = s₀ − g₀·s₁ + x − y′
dᵢ = sᵢ + s_{i−1} − gᵢ·s_{i+1}        1 ≤ i ≤ N−2
d_{N−1} = s_{N−1} + s_{N−2}
v = x + Σ aᵢ·dᵢ
y = +1（v ≥ 0）或 −1
s ← d；y′ ← y
```

- 级联积分器加前馈求和、相邻两级之间带谐振器负反馈。奇数阶的谐振器放在 (1,2)、(3,4)、(5,6) 级之间，即 g₁、g₃、g₅ 非零，其余为 0；第 0 级是直流零点的积分器。
- 线性化（y = v + e）后 `NTF(z) = 1 / (1 + aᵀ (zI − A)⁻¹ B)`，A、B 由上面的 d 方程给出。NTF 的零点是 A 的特征值：1 与 `1 ± j√gᵢ`。信号直通（v 里含 x），STF = 1，所以稳定性只由 NTF 决定。
- 附录 G 的“主系数”对应 a、“附加系数”对应非零的 g；四种算法差别只在 a 与 g（M1）。

## 2. 系数设计（M2）

### 2.1 按倍率的参数

| 参数 | 取值 | 由来 |
| --- | --- | --- |
| 信号带 f_B | 22.05 kHz，各倍率相同 | 参考各组的零点在赫兹上固定，且恰好落在 0–22.05 kHz 的 Legendre 最优位置 |
| 带内噪声的积分带 | 0–20 kHz | 与 SNR 的测量带一致 |
| 采样率 | DSD64/128/256/512 = 2.8224/5.6448/11.2896/22.5792 MHz | — |

### 2.2 零点

- 取 N 阶 Legendre 多项式 P_N 的正根 r_k（Newton 迭代，Chebyshev 节点作初值）：5 阶 0.5385、0.9062；7 阶 0.4058、0.7415、0.9491。这是使带内噪声积分最小的零点位置。
- 零点频率 f_k = r_k · f_B：5 阶 11.87、19.98 kHz；7 阶 8.95、16.35、20.93 kHz。
- `g = tan²(2π f_k / fs)`，按 f_k 从低到高放进 g₁、g₃、g₅。

### 2.3 极点的参数化与目标

- N 个极点直接作优化变量：复极点对用（半径、角度），实极点用实数值；`D(z) = Π(z − p)` 首一。`Q(z) = det(zI − A)` 由 g 决定，`NTF = Q/D`，h₀ = 1。不需要多项式求根。
- 初值：N 阶 Butterworth 高通模拟原型，预畸变后双线性变换（极点有闭式解），截止二分到 H∞ = 1.5。
- 目标：0–20 kHz 上 512 点的带内 NTF 均方根（dB）。罚项 `1e5·max(0, H∞ − h)² + 1e5·max(0, ‖h‖₁ − l)²`；任何极点半径 ≥ 0.995 视为不可行。H∞ 在 20 kHz–fs/2 的 6000 点上取，‖h‖₁ 用 16384 点冲激响应。
- 优化器：Nelder–Mead，每个约束点从初值起跑 3 轮（每轮 ≤ 6000 次迭代，下一轮从上一轮的结果开始）。

### 2.4 稳定性：选择与精修

稳定性仿真（选择、精修与验收共用一个定义，2026-11-09 明确）：

- 使用 §1 的非线性结构，并按 2026-11-09 裁定令首级为 `d₀ = s₀ − g₀·s₁ + x′ − y′`；每样本末尾 `s ← d；x′ ← x；y′ ← y`。每个幅度独立初始化 `s = 0、x′ = 0、y′ = +1`。
- 幅度指调制器内部输入 `x` 的峰值，即生产路径乘 0.5 后的量，不是外部 PCM 幅度。测稳定余量时不执行 ±0.5 钳位，也不执行失稳复位；生产路径仍钳位，实际 `|x| ≤ 0.5`。
- 基准波形使用 Go 的 `float64`、`math.Sin`，1 kHz、初始相位 0：`sample[n] = math.Sin(2*math.Pi*1000*float64(n)/float64(fs))`，`x[n] = amplitude * sample[n]`，`n` 从 0 开始。保留该表达式的运算顺序和 Go 常量折叠；不能改写为先除以 `fs` 再乘 `n`，也不以 NumPy 的正弦采样替代。
- 幅度从 0.45 起以 0.01 递增（用整数档位除以 100），每档 `2¹⁹ × (倍率/64)` 个样本。每个样本更新后，任一积分器状态绝对值超过 `1e8` 即判失稳；按幅度升序遇首次失稳立即停止，上一档为稳定上限。7 阶正常运行时末级积分器约 `1e5`，阈值不能更低。

**边界采样敏感性**：稳定上限只描述上述固定波形与有限样本长度，不是对任意相位或浮点采样扰动的保证。同一入库 Clans5/DSD64 系数、同一生产递推，Go 基准波形测得 0.56，原 NumPy 零相位序列测得 0.53。两种采样的角频率常量相差 1 ULP，另有正弦函数的舍入差异；DSD64 的 524288 个样本中有 427325 个不同，最大差 `2.2737367544323236e−13`。这属于边界附近的数值敏感性，不是递推、幅度定义或状态更新时机不同。离散非线性仿真不保证稳定性随幅度单调，某个更高幅度单独通过也不改变升序首失稳的上限定义。

**一次性多相位补充检查（2026-11-09）**：直接提取生产 `sdm.go` 的递推（不钳位、不复位），按上面的初始化、样本数和逐样本 `1e8` 判据，仅运行内部幅度 0.50、0.55 两档。每组使用 Go 初始相位 `0、π/8、…、7π/8`，以及原 NumPy 零相位序列；Go 相位在上述正弦参数末尾相加。16 组 × 9 序列 × 2 档共 288 个唯一用例，各执行一次，未扩大扫描。下表“全部稳定”指九条序列均未失稳；相位均指 Go 序列，NumPy 单列。

**标准 5/7 阶**：h = 1.5（Lee 准则），l 取 3.8, 3.9, …, 4.6；每个网格点按 §2.3 优化出一组，按带内噪声从低到高排序，取第一组稳定上限 ≥ 0.60 的。

**Clans 5/7 阶**：只靠 H∞ 与 ‖h‖₁ 间接约束不够——在稳定上限 ≥ 0.55 的前提下，网格选出的 Clans 5 阶带内噪声比参考高 0.1–2.6 dB。所以多一步直接以仿真为约束的精修：

1. 从 4 个约束点 (h, l) = (1.6, 4.0)、(1.65, 3.8)、(1.8, 3.4)、(2.0, 3.4) 各按 §2.3 优化出一组作起点；
2. 对每个起点再跑 Nelder–Mead（自适应参数，≤ 2500 次迭代），目标 = 带内噪声 dB + 30 × k，k 是从第一个失稳幅度到 0.56 之间的档数（按幅度升序仿真，遇到失稳即停，所以失稳的点很快被否掉）；
3. 4 个结果里取稳定上限 ≥ 0.56 且带内噪声最低的一组。

- 标准阶与 Clans 的分别：标准阶守住 H∞ = 1.5 与 0.60 的稳定余量；Clans 不限 H∞，用稳定余量换更低的带内噪声，稳定上限比验收下限 0.55 多留 0.01（钳位后调制器输入最大 0.5）。
- 精修的成本：每次目标计算最多 12 次仿真，DSD512 一个起点约 15 分钟；Go 实现会快于 Python 原型（原型的仿真也是 C 写的，开销主要在进程调用）。

### 2.5 实现结构的系数

- `D − Q` 关于 a 是线性的：在 3N 个复数点 `z_k = 1.05·e^{jθ_k}` 上解 `aᵀ (z_k I − A)⁻¹ B = D(z_k)/Q(z_k) − 1`，实部虚部叠成 6N×N 的最小二乘（Householder QR）。
- 核对：用 §1 的结构做线性冲激仿真，与 `Q/D` 的冲激响应比，最大误差 ≤ 1e−9，否则生成失败。

### 2.6 生成器与产物

- `backend/internal/dsp/sdm/internal/gen`（main 包，只用标准库），`sdm` 包里 `//go:generate go run ./internal/gen -out coeffs_gen.go`。整次生成在本机几分钟（仿真是 Go 写的紧循环）。
- `coeffs_gen.go` 提交入库，每组附注释：标准阶选中的 l、Clans 胜出的起点，实测 H∞、‖h‖₁、带内 NTF 均方根、稳定上限。CI 不重新生成，测试直接检查入库系数的性质（§6.1）。改方法时重新生成并在 PR 里对比注释里的指标。
- 不用 Python：生成要跑大量调制器仿真，Python 逐样本循环太慢；Go 标准库够用（无需求根、无需线性规划）。

## 3. 处理（M3、M4）

### 3.1 接口

```go
package sdm // backend/internal/dsp/sdm

type Algorithm int // Order5, Order7, Clans5, Clans7

func New(alg Algorithm, dsdRate int, channels int) (*Modulator, error) // dsdRate 只能是 64/128/256/512 倍 44.1 kHz；按倍率选系数
func (m *Modulator) Process(in [][]float64) []byte // len(in[c]) 必须是 8 的倍数；返回 样本数 × 声道 / 8 个字节，切片归 Modulator 所有
func (m *Modulator) Latency() int                   // 0
func (m *Modulator) Reset()
```

- 与 ⑧ 量化器一样是链的出口形态（浮点进、字节出），不是父设计 §3.1 的 `Processor`；返回切片的归属、`Latency`、`Reset` 的约定与 §3.1 相同。
- 48 kHz 族的 DSD 率暂不支持（没有对应输出端），`New` 返回错误。

### 3.2 每个样本

- `x = clamp(0.5 · in, −0.5, +0.5)`（PCM ±1 满刻度对应调制器 ±0.5）。
- 按 §1 更新、量化；比特 1 表示 +1。

### 3.3 打包与布局

- 每声道每 8 个比特打成 1 字节，**最早的样本放最高位**（MSB 先）。
- 输出字节按声道交错：`[第 0 字节组: 声道0, 声道1, …][第 1 字节组: …]`，与参考稿 §5.4 的 DSD 交错字节布局一致；字节数 = 块 × 声道 / 8（M3）。
- 块长由调用方按 `DSD 采样率 / 5` 给（DSD64 为 564480，是 8 的倍数）；不是 8 的倍数时 panic（调用方的编程错误）。

### 3.4 完整性自检（M4）

- `New` 时对（算法、倍率、阶数、a、g 的 IEEE 位模式）算 FNV-1a 64 位校验字，存在对象里。
- 每次 `Process` 开头重算并比较；不一致时**整块输出 `0x69`**（DSD 静音），计数加一，不抛错——保护下游设备。成本是每块十几个数的哈希。

### 3.5 失稳复位

- 每处理完一个字节（8 个样本）检查该声道状态的最大绝对值，超过 1e9 时把状态清零、`y′` 置 +1，计数加一。
- 理由：1 比特调制器失稳时输出满幅方波，会损伤下游设备；钳位只能保证正弦等典型输入稳定，接近 ±0.5 的直流类信号仍可能失稳。开销是每 8 个样本 N 次比较。

## 5. 与参考稿的对应和注意

### 5.1 正文 §6.7 的标注错位

正文 §6.7 列的两组系数与附录 G 的标注对不上（正文“7 阶”是附录 Order7/DSD512，正文“5 阶”是附录 Clans5/DSD64）。对照一律以**附录 G 各段的标题**为准，正文那两组不使用。

### 5.2 附录 G 的 7 阶少列了附加系数

- 7 阶需要 3 对零点，附录每组只给两项附加系数：Order7、Clans7 的 DSD64–256 只有一项非零，对应 20.93 kHz（第三个 Legendre 零点）；Clans7/DSD512 的两项对应 8.95 与 16.35 kHz。另一份同源的系数表（CSV，更多位小数）内容相同，也只有两项。
- 把缺的按 Legendre 位置补上后，参考 7 阶的 H∞ 落在 1.45–1.49，像一个正常设计；不补时带内噪声高 20 dB 以上、不像一个正常设计。
- 结论：参考的 7 阶也是 3 个谐振器，附录少抄了一项。本机对照按“补齐后”的参考比较。补齐后的参考带内噪声更低，是两种读法里更难达到的基准；我们对它不劣，按原样读也一定不劣。
