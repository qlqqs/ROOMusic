# 界面极简

## 目标

界面改成极简风格，信息一眼看得清：
- 换成常见的无衬线字体，字号整体缩小；
- 只有图标的按钮不带边框；
- 曲目行和播放条里的文字按钮换成图标；
- 新建成员改成弹窗。

对应用户反馈 2、3、4b、5、9、10（见 [父任务](../11-07-ui-minimal-and-catalog-fixes/prd.md)）。

## 已确认事实

- **字体**：
  - `frontend/src/styles/fonts.ts` 自托管三款可变衬线字体：Cormorant Garamond（标题）、Lora（正文）、Noto Serif SC（中文）。`package.json` 依赖三个 `@fontsource-variable/*` 包。
  - `frontend/src/styles/tokens.css` 的 `--font-heading`、`--font-body` 都是衬线字体栈。
  - 字阶是 12/14/15/17/20/25/36/48px，页面标题 48px。
  - 设计规范 `frontend/DESIGN.md` 第 3.2 节（字体与字号）按 Classical 方向定义了这些值。
- **曲目行**：
  - 共用组件 `frontend/src/app/routes/track-actions.tsx`，包括播放按钮（文字可配：“播放”“从这首开始播放”）、心形、“更多”菜单。
  - 使用它的页面：专辑详情（`album-detail-page.tsx:52-59`、`features/catalog/components/release-media.tsx`）、收藏、歌单详情、历史、艺人详情、搜索结果、正在播放、播放条。
  - 用户截图里，这排动作在曲目的第三行（标题行、作曲行之下），每个都是带边框的文字按钮。
- **播放条**（`features/player/components/player-controls.tsx`）：
  - 上一首、播放、下一首是带边框的图标按钮；
  - 播放模式是 `MenuButton`，文字是“播放模式：顺序”；
  - 静音按钮是 18px 的 `Volume2`，带边框。
- **艺人概况**：`features/catalog/components/artist-meta.tsx` 生成“1 张专辑 · 2 首曲目 · 专辑艺人、曲目艺人”，艺人列表、艺人详情、搜索结果的艺人栏和“可能是同一位”候选页都在用。
- **新建成员**：
  - `features/members/components/create-member-form.tsx` 是嵌在成员页里的表单：用户名、密码（说明“至少 12 位，可用英文字母、数字和符号。”）、确认密码。
  - 共享组件里已有 `ModalDialog`（重置密码对话框在用）。

## 需求

- R1 **字体**：
  - 全站改用系统无衬线字体栈：苹方（PingFang SC）、微软雅黑（Microsoft YaHei）、思源黑体（Noto Sans CJK SC / Source Han Sans SC）和系统 UI 字体；
  - 删除三款衬线网络字体和它们的依赖；
  - 时长、计数、进度这类数字用等宽数字。
- R2 **字阶**：
  - 整体缩小：正文 14px，次要文字 12–13px，页面标题不超过 24px，分组标题相应缩小；
  - 控件高度和间距相应收紧，触屏和窄屏仍不小于 44px。
- R3 **图标按钮**：
  - 全站只有图标的按钮都去掉边框；悬停和按下时显示浅色背景，键盘焦点环保留；
  - 每个都有读屏名和悬停提示。
- R4 **曲目行**：
  - 播放、心形、更多三个图标按钮移到标题行右侧，右对齐，放在时长左边；
  - 去掉“从这首开始播放”“播放”“更多”这些文字，悬停提示和读屏名保留原意（如“从这首开始播放”）；
  - 所有使用共用曲目动作的列表一起改；
  - 窄屏下标题太长时省略或换行，图标和时长不被挤出、不折到下一行。
- R5 **播放模式**：
  - 一个图标按钮显示当前模式，顺序、列表循环、单曲循环、随机各用一个图标；
  - 每点一下切到下一种模式；
  - 悬停提示和读屏名是当前模式名。
- R6 **喇叭**：静音按钮的图标缩小到 16px、无边框，和音量滑条对齐。
- R7 **艺人概况**：所有用到它的地方都只显示数量，例如“1 张专辑 · 1 首曲目”。
- R8 **新建成员**：
  - 成员页只放一个“新建成员”按钮，点开弹窗卡片，里面是用户名、密码、确认密码和“创建”“取消”；
  - 创建成功后关闭弹窗，在列表上方提示；
  - 失败时在弹窗里显示错误，保留已填内容；
  - Esc 或取消直接关闭，不创建成员。
- R9 **按钮、标签和卡片变轻**（用户 2026-11-07 选定）：
  - 每个页面或区块只有主要操作保留按钮外观（例如专辑页的“播放整张专辑”、成员页的“新建成员”）；
  - 其余文字按钮去掉边框，悬停或按下时才显示浅色底；
  - 状态标签（如“成员”“已停用”“需要关注”）去掉边框，改用淡底色；
  - 卡片和分隔线变淡；
  - 配色不变。
- R10 **规范**：`frontend/DESIGN.md` 和相关规范改成新的字体、字阶、按钮和标签规则，不再保留 Classical 衬线的描述。

## 约束

- 界面文案不写防御性说明，也不写权限、实现细节的解释；必要的说明用一句简短的日常话。
- 测试只补改动直接影响的行为，只跑受影响的 Vitest 和 Playwright 用例，不跑全量。
- 现有的 axe 无障碍检查继续通过。
