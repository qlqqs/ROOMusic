# 扫描：读文件

父任务：`.trellis/tasks/11-26-curation-chain-review`。每条决定的现状、依据和代码位置见父任务 `prd.md` 的对应段落（下表“出处”一栏）；规则汇总见 `docs/architecture/adr/0009-curation-chain-review.md`。

本任务只实现下面列出的决定，不改其他段的行为。实施中发现某条决定做不到或需要改，先停下报告，由主代理回父任务问用户。

## 目标

按父任务 A1.1、A1.2、A1.3、S2、S5、S6 的决定，改扫描读文件这一层。

## 范围

| 事项 | 出处 | 要做的 |
| --- | --- | --- |
| 读到一半文件还在写 | A1.1 表 | 读前读后各取一次修改时间，变了就丢掉这次结果，不覆盖旧数据；等下一次扫描或目录监听再读 |
| 补读字段，只读不用 | A1.2 表 | 读出并存好：总曲数；总碟数（小于碟号时改成碟号，0 当没提供）；完整的发行日期、原始发行日期；单曲、现场、私录、EP、原声、主版本标记；录制或演出日期；音量增益与峰值（去掉 dB 后缀）；同步歌词（超过 75% 的行带时间戳才算）；播客与有声书标记。读取规则按设计稿；不用于显示、整理、播放 |
| 注释 | B2“读注释标签” | 读 ID3 的 COMM、Vorbis 的 COMMENT 与 DESCRIPTION、MP4 的 ©cmt、APE 的 Comment，存好，先不用（子任务 8、9 交给模型） |
| 流派编号 | A1.2 表 | “(17)”这类按 ID3v1 编号表翻成名字；TCON 第一个值是 Podcast、Literature 时当媒体类型，不当流派 |
| 按文件头判格式 | A1.2 表 | 音频扩展名和没有扩展名的文件，按文件头判断真实格式，交给对应的解析器；“认不出格式”和“读文件出错”分开记；图片、文本、CUE 等已知非音频扩展名不读文件头 |
| 艺人名拆分 | S5 | 只按分号、全角分号、` / `、`feat.`、`ft.`、`with`、顿号、换行、NUL 拆；`&`、逗号、紧贴的 `/` 不拆；去掉受保护名单和“`&` 两边都是多个词才拆”（`backend/internal/catalog/metadata/artist.go`） |
| 旧编码挪进扫描 | S2、A1.5 | 同一张专辑里只有一种编码读得通的，扫描直接按它解整张。几种都读得通的保持原样、做上标记、不拿去搜索；配了模型时由子任务 8 交本地辅助。整理那边写入旧编码解码的程序路径随之去掉 |
| 古典名单 | A1.3 | 中文按名单认（古典、古典音乐、古典乐），不再按“含古典”（`backend/internal/catalog/metadata/genre.go:34-46`） |
| 只有文件名、没有标签 | A1.5 表第 1 行 | 不按“ - ”拆出艺人（`backend/internal/catalog/ingest/filename_numbers.go:157-178`）；整串去掉开头曲号和格式字样当标题，艺人为“未知艺术家”；专辑名用目录名，目录名固定格式的识别照旧 |
| 播客、有声书不送去整理 | A2.1 表 | 有媒体类型标记的专辑不进整理队列。从子任务 5 挪到这里，免得 5 等本任务的字段 |
| 解析规则版本 | A1.2 末条、A4 | `CommonVersion` 只升一次 |
| 扫描规范 | 文档 | 改两处不符：`.trellis/spec/backend/library-scan-pipeline.md:13`（.dsf/.dff 已支持）、`library-scan-incremental.md:32`（解析版本）；读标签规范补上新字段和拆分规则 |

## 不做

- 新读字段的用法；归组（子任务 3）；目录监听（子任务 4）。
- 合作标记以外的拆分判断（子任务 8）。

## 依赖与协调

- 和子任务 3 同批做。两边都动扫描版本号：本任务只升 `CommonVersion`，子任务 3 只升 `GroupingVersion`，合入后各只升一次。

## 验收

- [ ] 每条规则各有合成文件的对照样本：读取中被改动的文件不写入这次结果、旧数据保留；新字段的几种写法；流派编号与媒体类型；扩展名和内容不符；拆名字的每种标记与不拆的 `&`、逗号；旧编码的唯一读法与几种读法；古典名单；只有文件名的。
- [ ] 升级后第一次扫描重读全部文件。标签完整、一目录一张的普通专辑，结果除 S5、古典名单带来的变化外不变。
- [ ] 新规则各有对照样本，用合成数据；只跑改动涉及的包和用例。
- [ ] 改到的规范同步改（见各行）。
- [ ] 合入前跑依赖门禁 `TestPackageDependencyDirections`。
- [ ] 子任务 1 合入后，对固定样本回归：认错 0 张；认对、请求数、用时不比基线差，差值写进交付说明。
