# 全局出站代理

## 目标

管理员可以在设置页配置一个全局代理（HTTP 或 SOCKS5）。服务端访问外网时都经过这个代理，访问局域网和本机时直连。

适用场景：所在网络访问不了部分来源（例如 archive.org 上的封面、维基百科、模型接口），或者服务器只能经代理上网。

## 现状

- 所有外部请求都经过 `backend/internal/platform/egress` 的 `NewClient`，包括：
  - 元数据来源 `sources/request.go:439`；
  - 管家网页搜索与读取 `steward/web/search.go:81`、`fetch.go:80`；
  - 模型接口 `steward/httpapi/outbound.go:34`；
  - 艺人资料与媒体佐证 `curation/stewardtools/*`；
  - 匿名统计 `insights/service.go:83`。
- 这个客户端有意不读取环境代理（`client.go:42`），并在拨号时按策略检查目标 IP：`PublicOnly` 只允许公网地址，用于防止网页读取打到内网。
- 局域网设备（AirPlay、Cast、UPnP、局域网串流、PTP）不走这个客户端，本任务不涉及。
- 凭据加密已有 `backend/internal/platform/secret`。

## 需求

- **R1 配置**：
  - 在设置“管理”分组下新增“网络”栏目（仅管理员），包含：
    - 代理开关；
    - 类型：HTTP 或 SOCKS5；
    - 主机与端口；
    - 可选的用户名和密码。
  - 密码只写不读：保存后接口只返回“已设置”，留空表示不修改，可以单独清除。
  - 保存后立即生效，不需要重启。
- **R2 范围**：所有经 `egress.NewClient` 发出的外部请求都走代理。
- **R3 直连**：以下目标不走代理，一律直连：
  - 字面量为回环、私有、链路本地地址的目标；
  - 主机名本地解析后全部为非公网地址的目标（例如管理员填的局域网模型地址）；
  - 上游模拟服务。
- **R4 远端解析**：
  - 走代理的请求把主机名交给代理去解析。SOCKS5 按 socks5h 方式；HTTP 代理对 HTTPS 用 CONNECT、对 HTTP 直接转发。这样本地 DNS 被污染时也能访问。
  - 地址策略仍然生效：
    - `PublicOnly` 和 `PublicOrAllowlist` 照旧先在本地解析检查，含禁用地址就拒绝；
    - `Unrestricted` 不检查。
  - 代理服务器本身的地址可以是局域网地址，不受目标策略限制。
- **R5 测试**：
  - 设置页提供“测试连接”，通过当前填写的代理（未保存的也可以）请求一个固定的公网地址，例如 MusicBrainz 首页。
  - 返回成功或失败，以及失败原因：代理连不上、认证失败、目标不可达或超时。
- **R6 错误区分**：
  - 代理不可用（连不上、认证失败）时，来源请求按“来源不可用”处理，进入现有退避，不计为查无结果。
  - 日志与诊断里不出现代理密码。
- **R7 兼容**：未开启时，行为和现在完全一样，仍然不读取环境代理。

## 验收标准

- [x] V1：开启 HTTP 代理与 SOCKS5 代理（带认证与不带认证）时，来源请求、模型请求、网页读取都经过代理。用本地测试代理计数验证。
- [x] V2：局域网与回环目标在开启代理时直连，代理计数为 0。
- [x] V3：`PublicOnly` 请求的目标解析到私有地址时，开启代理后依然拒绝。
- [x] V4：
  - 密码加密存储，接口与日志不返回明文；
  - 留空保存不改动密码，清除后密码失效。
- [x] V5：测试连接能区分成功、代理连不上、认证失败、超时。
- [x] V6：代理不可用时，来源进入退避，整理项不被记为未收录。
- [x] V7：未开启时，既有出站测试全部通过，行为不变。
- [x] V8：前端有“网络”栏目，用图标加读屏名，交互与现有设置页一致；有单元测试。合同文档同步。

## 不做

- 按来源分别设置代理或绕过名单（以后有需要再加）。
- 读取系统环境变量 `HTTP_PROXY` 等。
- 局域网设备流量。
- PAC 或自动发现代理。

## 规划决定记录

- 路线：沿用用户的长期授权（记忆“规划完直接实现”）：规划写全，主代理选定推荐方案后直接实施，交付时列出替用户做的决定。
- 主代理替用户做的决定：
  - 配置在设置页，不用环境变量；
  - 模型接口也走代理；
  - 局域网自动直连，不提供手动绕过名单；
  - 远端解析；
  - 测试连接默认访问 MusicBrainz 首页。
