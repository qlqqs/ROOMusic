# 走查遗留五项

## Goal

上一轮界面走查（`archive/2026-11/11-24-ui-detail-polish`）记下但没改的五处问题，这次一并处理。范围按通用曲库考虑，不按某个人的曲库定。

## Requirements

1. **混合文件夹里没有专辑标签的曲目不再以文件夹名当专辑名。** 同一目录里有的文件带专辑标签、有的没有，按专辑拆开时，没有真实专辑标签的文件各自成一张“未知专辑”，与注册根目录散曲、子目录整组散曲的现有做法一致。整目录都没有专辑标签的真实专辑文件夹，以及能被识别的专辑目录名，仍沿用现有归组。已有曲库下次扫描时生效。
2. **艺人页的专辑计数与列表对得上。** 页头的“N 张专辑”仍是以任何身份参与的专辑数；页面上分成“专辑”（作为专辑艺人）和“参与的专辑”（以其他身份参与、不是专辑艺人）两栏，各自计数、分页，两栏合起来对应页头的数。没有参与的专辑时不出现这一栏。
3. **有损格式不显示位深。** AAC（m4a 里的 mp4a）不再记录位深；信号路径、播放栏格式、曲目信息、版本对比随之不显示“16 bit”。ALAC 的真实位深照旧。已有曲库下次扫描时重新解析这些文件。
4. **桌面播放栏直接调音量。** 宽屏时播放栏右侧有一条常驻的横向音量条，拖动或键盘直接调；喇叭图标只负责静音与取消静音。设备不能调音量（iPhone / iPad 网页、只能在设备上调的局域网设备）时，音量条不可用并说明原因。窄屏不放音量条（沿用现状）。
5. **没配好模型时，手机底部标签栏不占一格“管家”。** 管家处于“还没接上模型”的状态时，底部标签栏不显示它；接上后（包括密钥失效、模型不支持工具这类已配置但不可用的状态）照常显示。桌面侧栏不变，仍可从侧栏和设置进入引导页。

## Acceptance Criteria

- [ ] 合成曲库：`Downloads/` 里两首带不同专辑标签、一首没有专辑标签的曲目（目录按专辑拆开），扫描后没有名为“Downloads”的专辑；没有专辑标签的那首在“未知专辑”下。只有一种专辑标签时，无标签的曲目仍按现有多数规则并入那张专辑。
- [ ] 整目录无专辑标签的专辑文件夹仍按文件夹归成一张专辑（现有测试不变）。
- [ ] `GET /api/v1/artists/{id}/albums?participation=appears_on` 只返回以其他身份参与、且不在默认（专辑艺人）列表里的专辑组，带 roles；`q`、分页与 `participation=any` 同样可用；非法值仍返回 `invalid_artist_participation`。
- [ ] 艺人页显示“参与的专辑”一栏（有数据时），带“N 张”计数与分页，翻页写进地址。
- [ ] AAC 文件解析后 `bit_depth` 为空；ALAC 位深不变；`.m4a` 解析版本号与归组版本号按规则升级。
- [ ] 桌面宽度播放栏有常驻音量条；读屏名、键盘操作、静音切换可用；不能调音量的设备上音量条禁用并有提示。
- [ ] 手机宽度：管家未配置时标签栏没有“管家”；已配置时有。
- [ ] 相关单元测试、Go 测试、受影响的 e2e 用例通过。
