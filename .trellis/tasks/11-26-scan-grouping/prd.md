# 扫描：归组

父任务：`.trellis/tasks/11-26-curation-chain-review`。每条决定的现状、依据和代码位置见父任务 `prd.md` 的对应段落（下表“出处”一栏）；规则汇总见 `docs/architecture/adr/0009-curation-chain-review.md`。

本任务只实现下面列出的决定，不改其他段的行为。实施中发现某条决定做不到或需要改，先停下报告，由主代理回父任务问用户。

## 目标

按父任务 A1.4、S4 和 S6 里归组部分的决定，改扫描的归组。

## 范围

| 事项 | 出处 | 要做的 |
| --- | --- | --- |
| 混放目录 | S4 | 先看整个目录的曲号是否从 1 到 N、不缺不重，依次用四种读法检验（标签的碟号和曲号；文件名推断的；两者混合；只用文件名曲号），任一种连续就整目录算一张；不连续就按音频格式分开再检验；仍不连续才按专辑名拆，有曲目缺专辑名时按“艺人 + 专辑名”分。上次第 7 条规则的对照样本里，曲号连续但专辑名不同的，预期改为合成一张 |
| 碟片子目录 | A1.4 表 | disc、disk、cd 加编号的目录并到上一级，碟号从目录名读；带名字的碟目录（“CD1 - 早期作品”）并进同一张，名字记为碟标题；Bonus、特典等附加碟并进同一张，排在正碟后面（`backend/internal/catalog/ingest/organizer.go:287-470,682-760`） |
| 专辑名比较 | A1.4 表 | 用合并键：忽略大小写、标点、空格、变音符号；去掉一首异名、括号后缀不同两条补丁（`organizer.go:1362-1408`） |
| 没写专辑艺人时 | A1.4 表 | 有人过半用他；没人过半时 2–4 位并列为“A / B”；5 位以上算群星（`backend/internal/catalog/metadata/compilation.go:48`） |
| 版本词 | A1.4 表 | 从目录名、专辑名的括号里抽出存好；年份和 EP、单曲、原声不算；不参与归组和身份 |
| 附属文件 | A1.4 表 | 专辑目录及其 Art、Artwork、Scans、Extras 子目录里的图片和文档绑到专辑，图片记格式和尺寸；先存好，不做查看界面 |
| 排序键 | A1.4 表 | 去标点、折叠变音、开头的英文 “The ” 挪到末尾；用于艺人、专辑列表排序 |
| 缺碟号、缺曲号 | A1.5 表 | 明确写出的照用（CD2、1-03、A1）；不从“曲号从 1 重新开始”推断第 2 碟（上次第 4 条规则改为配了模型时由子任务 8 判断）；没编号的按文件名顺序排，但不写曲号 |
| 同一字段几首不一致 | A1.5 表 | 有明确多数照多数；打平就不填，标“有冲突”（`organizer.go:93-158`） |
| 归组规则版本 | A4 | `GroupingVersion` 只升一次 |
| 扫描规范 | 文档 | `.trellis/spec/backend/library-scan-grouping.md`；`library-scan-incremental.md:35`（归组版本） |

文件里的 MusicBrainz 专辑编号照旧不参与归组。

## 不做

- 读文件（子任务 2）；碟号、曲号和混放目录里“只能猜”的情况（子任务 8）。
- 版本词、附属文件的显示与查看。

## 依赖与协调

- 和子任务 2 同批做。本任务只升 `GroupingVersion`，子任务 2 只升 `CommonVersion`。
- 合并键与子任务 5 共用（A2.3 的专辑名比较），放在共用的位置（如 `backend/internal/catalog/textnorm`）；先合入的一方放，后合入的复用。

## 验收

- [ ] 每条规则有对照样本：混放目录的三步；碟目录的三种（编号、带名字、附加碟）；合并键；专辑艺人的过半、2–4 位、5 位以上；版本词；附属文件；排序键；碟号和曲号不推断；打平标“有冲突”。
- [ ] 升级后第一次扫描重新归组；专辑、曲目编号尽量延续，对应、收藏、手动修改不丢。
- [ ] 新规则各有对照样本，用合成数据；只跑改动涉及的包和用例。
- [ ] 改到的规范同步改（见各行）。
- [ ] 合入前跑依赖门禁 `TestPackageDependencyDirections`。
- [ ] 子任务 1 合入后，对固定样本回归：认错 0 张；认对、请求数、用时不比基线差，差值写进交付说明。
