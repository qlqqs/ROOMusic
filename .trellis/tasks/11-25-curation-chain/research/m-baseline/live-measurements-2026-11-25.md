## 运行命令

在 `backend/` 执行以下命令，退出码均为 0。HTTP/2 调试输出只留在 `temp/` 中。

```bash
mise exec -- go run ./cmd/roomusic-curation-bench mb-rate
GODEBUG=http2debug=2 mise exec -- go run ./cmd/roomusic-curation-bench tolerance
GODEBUG=http2debug=2 mise exec -- go run ./cmd/roomusic-curation-bench real-corpus \
  -out ../temp/real-corpus/ -ffmpeg "$(../scripts/ffmpeg-pinned.sh)"
GODEBUG=http2debug=2 mise exec -- go run ./cmd/roomusic-curation-bench tolerance \
  120da7c5-dd0f-38cd-abcd-3c3b8f0dcde9 8beb26c6-8fe0-36d8-921e-f6bb2161b757
```

解析检查从 `temp/metrics-corpus-inspect/` 运行 `mise exec -- go run -mod=mod . ../real-corpus`。八首的 PCM 抽查用 Python 调用 `ffmpeg -v error -nostdin -i <文件> -map 0:a:0 -c:a pcm_s16le -f s16le -`，两项检查均通过。
