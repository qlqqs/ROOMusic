# 多声道降混

父任务：[音频算法对标](../11-08-audio-dsp-reference-port/prd.md)。参考稿（本机 `~/.local/share/roomusic-reference/reference-design.md`） §6.8。算法默认照参考稿的参数和公式实现，只有确信同样好或更好时才偏离，并写明理由。所有算法只在后端（Go）实现（父任务 A1）。

## 需求

- **D1 矩阵**（§6.8）：

  | 场景 | 基准增益 | 中置 | 环绕 | LFE |
  |---|---|---|---|---|
  | 5.0/5.1 → 2.0 | −6.0 dB | −3 dB 双写 L/R | −6.0 dB 并入同侧 | 丢弃 |
  | 7.1 → 2.0 | −6.8 dB | −3 dB 双写 | 后/侧环绕并入同侧 | 丢弃 |
  | 7.1 → 5.1 | −3.2 dB | 保留 | 侧环绕等权相加 | 保留 |

- **D2 声道布局**：32 位掩码，位序即声道序号；4 声道默认按 4.0（L R C SC）解释，7 声道默认按 6.1。
- **D3 何时降混**：按输出端声明的声道数决定。多声道源在只支持双声道的输出上**默认降混**。偏离参考稿：参考稿在未启用降混时只取前两声道，会丢掉中置声道里的人声，所以默认改为降混。播放区设置里可以关。

## 验收

- 用每个声道放不同频率正弦波的 5.1、7.1 测试素材，输出各声道的成分和电平与矩阵一致。
- 信号路径显示“5.1 → 2.0”这类降混节点。

## 依赖

DSP 处理链与服务端渲染；输出端能力声明（播放区线）。
