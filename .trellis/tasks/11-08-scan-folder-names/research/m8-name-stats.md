# 八号机真实库目录名统计（只读，2026-11-08）

八号机 `/vol2/1001/ROOMusic` 与本机 `music/` 的文件清单（相对路径与大小）完全相同，统计在本机 `music/` 上执行（design.md 第 11 节的命令）。只记聚合计数与写法形状。

| 统计 | 结果 |
| --- | --- |
| 目录数 | 106（含根） |
| 含 disc/disk/cd 的目录名 | 2 个碟目录，形状 `Disc 9`；另有 4 个专辑目录名含介质标记而非碟号：`[CD]`（3 个，后接 `[唱片编号]`）、`{…, CD}`（1 个）；还有唱片编号里的 `BACD-` 这种写法 |
| 中文碟号写法（`第N碟/张/盘`、`碟N`、`光盘`） | 0 |
| 只放图片、不放音频的目录 | `Scans` 2 个、`Artwork` 1 个；另 2 个专辑目录本身只有图片（音频在其碟子目录里） |
| 图片文件名形状 | `9.png` 21、`cover.jpg` 15、`booklet - 9.png` 8；含 `front` 的：`box - front`、`inlay - front`、`preview - front` 各 1；另有 `inlay - back`、`box - back`、`disc - printing`、`disc - substrate`、`flyer - tour` |

## 结论（主会话定稿）

- 中文碟号写法不纳入解析器：真实库没有出现；`第一张` 一类写法还常出现在专辑名里（如“××的第一张专辑”），误认风险高于收益。
- 附属子目录名单保持 `scans`、`artwork`、`art`、`covers`，不加中文名（真实库没有）。
- `[CD]`、`{…, CD}`、`BACD-0001` 必须不被认成碟号，加进 3.3 解析对照表。
