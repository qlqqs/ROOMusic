# 我的页与概览资料库的卡片样式

## Goal

参照用户提供的手机设置页截图（分组圆角卡片、内缩分隔线、右箭头），统一调整两处移动端观感：

- “我的”页（`/me`，窄屏底部标签栏第四项）：从无底色的平铺列表改为分组圆角卡片。
- 概览页（`/`）的“资料库”与“资料库状态”：标题移到卡片外，数字改为宫格，状态表改为实心卡片。

## Background

- “我的”页：`frontend/src/app/routes/me-page.tsx`、`me-page.module.css`。现状各组是带底线的平铺行，分隔线贯穿整行、最后一行也有；只有账号行与“全部歌单”有箭头；最宽 640px。
- 概览“资料库”：`frontend/src/features/catalog/components/library-stats.tsx` 与同名 `.module.css`。现状四行“数字 + 单位”右对齐，左侧大片空白，标题在卡片内。
- 概览“资料库状态”：共用组件 `frontend/src/shared/ui/status-table.tsx` 与同名 `.module.css`（目前只有概览页使用）。现状描边浅底卡片，标题在卡片内，分隔线贯穿整行。
- 概览主栏区块（如“最近播放”）用 `Panel`：顶部细线加 h2，见 `frontend/src/shared/ui/panel.module.css`。
- 设计变量见 `frontend/src/styles/tokens.css`（`--color-surface`、`--color-divider`、`--color-hover`、`--color-pressed`、`--space-*`、`--fs-*`）。
- 已在临时工作目录做过概览部分的截图预览（390px 与 1440px），用户确认方向。

## Requirements

### 共同卡片样式

- C1 卡片：底色 `--color-surface`，圆角 12px，无描边，内容裁切在圆角内。
- C2 分隔线：同一卡片内相邻行之间一条 `--color-divider` 细线，从名称起始（图标或封面之后）到卡片右边缘；首行上方与末行下方不画。
- C3 交互：按下有 `--color-pressed` 底色；悬停底色只在 `(hover: hover)` 设备出现；键盘焦点环可见、不被圆角裁掉；减少动态效果时无过渡。

### “我的”页

- M1 账号行、“我的音乐”、“我的歌单”、“管理”、“设置与退出”各一张卡片（C1）。
- M2 组标题（我的音乐、我的歌单、管理）与“新建歌单”按钮在卡片上方，样式不变。
- M3 行左右内边距 16px，最小高度约 52px；图标、名称、计数/曲目数的顺序不变；行间分隔线按 C2。
- M4 进入子页的入口（我的音乐各项、歌单各项、全部歌单、管理各项、设置、账号）右侧有 `›`；待办计数在箭头左边；“退出登录”无箭头。
- M5 空歌单提示、退出失败提示在卡片内显示正常；宽屏同样是卡片样式，最宽 640px 不变。

### 概览“资料库”

- L1 标题“资料库”移到卡片外，样式与 `Panel` 一致（顶线 + h2）。
- L2 四项（专辑、曲目、艺人、作曲家）在卡片里排成 2×2 宫格，格间 1px 分隔线；每格大号数字在上、单位在下，左对齐。
- L3 可进入的格子（专辑、艺人、作曲家；数据为“—”时不可进入）整格是链接，单位后跟 `›`；曲目不可进入、无箭头。
- L4 读取中骨架与“还没有专辑”的提示在卡片内显示，内边距与格子一致。

### 概览“资料库状态”

- S1 标题移到卡片外，样式同 L1。
- S2 卡片按 C1，行间分隔线按 C2（从名称列开始）。
- S3 行文字 14px；状态值与箭头列对齐方式不变；扫描进度条、读取失败的“重试”照常显示。

## Acceptance Criteria

- [ ] 390px 宽截图：“我的”页为分组卡片、内缩分隔线、右箭头，无横向滚动（M1–M5）。
- [ ] 390px 与 1440px 截图：概览“资料库”为 2×2 宫格，“资料库状态”为实心卡片，两个标题与“最近播放”样式一致（L1–L4、S1–S3）。
- [ ] 每张卡片末行无分隔线，分隔线不贯穿图标列（C2）。
- [ ] “退出登录”与“曲目”格子无箭头，其余可进入项有箭头；待办计数与各链接的可访问名称不变（M4、L3）。
- [ ] `me-page.test.tsx`、`overview-page.test.tsx` 及 `status-table`/`library-stats` 相关单测通过；`npm run typecheck`、`npm run lint` 通过。
- [ ] e2e `a11y.spec.ts` 中窄屏“我的”页与概览相关用例无 serious/critical 违规（在 Playwright 镜像内运行）。

## Out of Scope

- 设置页（`/settings/*`）与其导航；底部标签栏（用户决定保持原样，不做滚动隐藏或侧边抽屉）。
- 路由、数据、入口的组成与顺序。
- 新增全局设计变量；12px 圆角只在这几处样式中使用。
