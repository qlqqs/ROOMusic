# 自动整理 H：发行的整张并入

## 目标

扫描把一张专辑拆成了几个发行时（碟目录没认出来、碟目录专辑名不同、碟号不连续、分在两个目录、散文件等，调研 S1–S10），管理员能把一个发行整张并入另一个，合起来成为一个多碟发行；重扫、增删文件、改名移动后仍保持；可撤销并回到合并前原样。两个本地发行对上同一个 MusicBrainz 发行、且是互不重叠的两部分时，由模型提出、审查通过后自动并入。

## 背景与已定事项

- ADR 0006 U6 把“发行的合并与拆分”纳入 M7（第 184、312 行），父任务 R13。调研见 `research/release-merge-split.md`。
- 2026-11-23 qlqq 选定：**先只做整张并入**（调研方案 C），拆分另立任务。理由：拆分没有任何已保存的强证据（调研 §5.3），扫描侧意图（方案 A/B）改动面与回归风险最大；整张并入覆盖最常见的“多碟被拆开”。
- 实现路线由主代理按“扫描核心不动、读取处不改、撤销简单”选定（见 design.md D1）：被并入发行的碟**实际挂到目标发行**，扫描按“碟原来属于哪个发行”认身份并照常写被并入方。读取侧约 94 处查询不用改；扫描侧只改认身份与写碟的几处。

## 需求

R1 人工整张并入：管理员在专辑页的“管理”里选另一个可见发行，先看预览（并入后的碟序、被隐藏的内容、收藏的去向），确认后并入。被并入发行的全部碟接在目标发行后面，被并入发行不再单独出现。

R2 重扫保持：之后的全量扫描、增量扫描、被并入方或目标方增删文件、同 root 内改名移动，合并都保持；被并入方新增的曲目跟着进目标发行，新增的碟接在后面；被并入方的扫描字段照常更新但不显示。

R3 发行级状态：目标发行的标题、修正、自动层、封面、外部对应、核对、归组、默认版本保持不变并对合并后的发行生效。被并入方的这些状态原样留在被并入方，合并期间不显示也不进入待认领，撤销后恢复。被并入方所在的专辑因此没有可见版本时，它的专辑收藏转到目标所在的专辑，撤销时转回。

R4 撤销：合并能从操作记录与专辑页撤销；撤销把碟还给被并入方、恢复碟号与收藏，两个发行回到合并前的样子。合并之后在合并发行上做的修正、曲目修正、归组等不妨碍撤销，也不被撤销带走（曲目修正跟着曲目走）。撤销之后自动整理不再提出同一对发行的合并。

R5 自动并入（强证据）：两个可见发行各有生效的 MusicBrainz 发行对应、指向同一个外部发行，且两边已对上的录音互不重叠时，程序生成待定项，模型提出 `merge_releases`，经独立审查后写入，来源为自动整理；证据不满足时后端拒绝或转人工；审查没通过、转人工的进入例外，管理员可采纳或不采纳。人工撤销过这一对、或人工把两边分到不同专辑的，不再自动提出。

R6 对话与 MCP：管家对话与 MCP 也能发起合并（与人工同一执行器，需要确认）。

## 验收标准

- A1 人工合并后：目标发行详情包含两边全部曲目，碟序符合 design.md D3；被并入方的发行页 404，不出现在专辑列表、搜索、艺人页、待认领；目标的标题等字段不变；播放、收藏曲目、歌单里这些曲目的位置显示为目标发行。
- A2 合并后做全量扫描、增量扫描（无变化时被并入方与目标方候选都能跳过）、给被并入方加一首、加一碟、删一首、目录改名：合并保持，发行 ID 不变，没有新建发行。
- A3 目标方自己新增一碟、碟号与已并入的碟冲突时，碟序按 D3 重新排，无唯一约束冲突。
- A4 撤销后：碟、碟号、收藏回到合并前；被并入方重新可见并带回它的修正与核对；合并后做的曲目修正仍在曲目上；被并入方原来是默认版本的仍是。
- A5 链式与边界：已被并入的发行不能再当来源或目标；已有发行并入的不能再并入别处；同一发行；不可见；合起来超过曲目上限，分别返回约定错误码，且不改变任何数据。
- A6 自动：符合强证据的一对由模型并入；录音重叠（例如同一张专辑的两种格式）、缺对应、对应未被操作记录佐证、有不再提出标记、人工分组隔开的，后端拒绝或转人工；撤销自动并入写入标记，之后不再提出。
- A7 例外采纳、不采纳，审查策略第 4 版的证据，按批与按来源撤销。
- A8 无合并的库，现有接口样本逐字不变；既有扫描身份测试全部通过。

## 不做

- 拆分（把一个发行的部分曲目分出去）与部分曲目改挂：另立任务，等有强证据来源（部分匹配）或真实需求。
- 跨 root 的特殊处理之外的“合并后再合并”链：不允许链，需要时先撤销再并到同一个目标。
- 被并入方被整张替换（新曲目 UUID）后的合并延续：新文件成为新发行，与认领的已知限制同类。
- 曲序与碟号的人工修正（U9 不变）。
- 旧链接 `/releases/<被并入方>` 跳转到目标：返回 404，记为已知限制。
