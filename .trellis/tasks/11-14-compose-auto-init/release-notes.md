## 安装与数据目录

- 新安装只需填写音乐目录，直接运行 `docker compose up -d --wait`。
- 首次启动自动生成数据库密码并保存到 `secrets/postgres_password`，重启和升级复用；也可首次手动指定。
- 数据库、应用数据和备份分别放在部署目录的 `postgres/`、`data/`、`backups/`，不再创建 Docker 数据卷。
- 容器名称由 Compose 项目生成，同一主机可以使用不同项目名运行多个实例。
- 应用、备份、恢复和重置密码命令统一读取数据库密码文件，支持特殊字符。

## 使用与迁移

新 Compose 配套 v0.7.0 及后续镜像。旧实例继续使用原部署配置和密码；替换 Compose 不会自动搬迁旧卷数据。

新布局迁移时，停止服务后复制完整部署目录并保留属主与权限，在目标机器使用相同 PostgreSQL 主版本启动。音乐或备份若使用外部目录，也需一并处理。日常在线备份继续使用应用内数据库备份功能。

本版未新增数据库迁移。未操作已有生产实例。
