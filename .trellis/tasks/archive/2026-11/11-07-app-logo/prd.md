# 应用 Logo 与图标

## 目标

ROOMusic 有自己的图标：浏览器标签、侧栏和登录页都能看到同一个"房子里放一张唱片"的标志。

## 底稿

用户用生图模型生成、已认可方向的三张图，在本任务 `refs/` 目录（不进 git）：

- `refs/icon-main.png`：主图标，铜色房子轮廓，里面一张深色唱片，唱片两侧各一条短纹路；
- `refs/icon-small.png`：小尺寸版，线条更粗，唱片没有纹路，只有中心白点；
- `refs/wordmark.png`：文字标志，仅作参考，本任务不采用（见"决定"）。

## 需求

- R1 **两个 SVG 图标**，按底稿手工重画成干净的矢量图形，不是位图描摹：
  - 主图标：对应 `icon-main.png`；
  - 小图标：对应 `icon-small.png`，16px 下能认出房子和唱片。
- R2 **图形要求**：
  - 颜色只用界面已有的两种：铜色 `#b68235`（`--color-accent`）和深色 `#201f1d`（`--color-text`）；唱片中心是白色；
  - 背景透明，房子内部透明；
  - 唱片完全在房子里面，和墙、屋顶、地面的间距均匀；
  - 修掉底稿的瑕疵：屋檐两侧多出的小圆头，屋檐和墙连接处里侧的小凹口。轮廓是一条粗细一致、拐角圆润的闭合线。
- R3 **浏览器标签图标**用小图标。浏览器是深色模式时，唱片换成浅色，避免在深色标签栏上看不见。
- R4 **侧栏顶部**：主图标加 "ROOMusic" 文字，桌面侧栏和窄屏顶栏都一样；仍然是回到概览的链接，可访问名称不变。
- R5 **登录、初始化、启动页**：品牌位置同样是主图标加文字。
- R6 图标只是装饰，读屏不重复读出。

## 决定

- 文字部分用界面现有字体排 "ROOMusic"，不做底稿里"两个 O 画成唱片"的效果。原因：小字号下唱片会变成两个实心黑点，和细的系统字体放在一起显得突兀。
- 不做 README 图片、PWA manifest 和 apple-touch-icon。

## 约束

- 界面上不加任何说明文字。
- 不新增依赖。
- 测试只做必要的：现有用例跟着改，不为图标本身另写测试。

## 验收

- [x] A1 两个 SVG 符合 R2，16px 和 32px 下都能认出来。
- [x] A2 浏览器标签显示小图标，深色模式下唱片可见。
- [x] A3 1440 和 375 宽度下，侧栏或顶栏、登录页的品牌位置截图：图标和文字对齐，大小协调，不挤压搜索框和菜单按钮。
- [x] A4 类型检查、lint 和受影响的现有测试通过；`backend/cmd/roomusic/web` 已重新构建，和源码一致。
