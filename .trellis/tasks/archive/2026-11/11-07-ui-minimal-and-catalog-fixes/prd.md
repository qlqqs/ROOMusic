# 界面极简与资料整理改进

## 目标

落实用户 2026-11-07 的 11 条反馈，具体是：
- 界面改成极简风格，信息一眼看得清；
- “我的音乐”在侧栏单独成组；
- 修正两条元数据规则（多流派、合唱被当成同一人）；
- 添加音乐目录时可以在界面上逐级选文件夹。

技术取舍（设计 agent 推荐、主会话裁决，详见各子任务 `design.md` 的“裁决结果”）：
- 流派读取字段 `genre` 直接改成数组 `genres`，修正字段键仍叫 `genre`；拆分符号是 `;`、`；` 和顿号 `、`，斜杠和逗号不拆。升级时用旧候选补全，不用重扫就能看到多流派。
- 括号别名信号放在新表 `artist_alias_signals`，同曲同身份共同署名的排除在读取时按艺人判断；艺人投影版本升到 2，升级后整理一次。
- 目录浏览接口是 `GET /api/v1/library-folders`，判定直接复用 `ValidatePath`；已添加的文件夹打标记，最多列 2000 个；路径框的说明句删掉。
- 迁移编号固定：0031 给重复艺人规则，0032 给多流派。

## 子任务与顺序

| 子任务 | 交付 | 顺序与依赖 |
| --- | --- | --- |
| [11-07-ui-minimal](../11-07-ui-minimal/prd.md) | 字体与字阶、图标按钮、曲目行、播放条、艺人概况、新建成员弹窗 | 第一个做，其他前端改动都在它的新样式上进行 |
| [11-07-sidebar-my-music](../11-07-sidebar-my-music/prd.md) | 侧栏三组、我的音乐拆成独立页面、两处改名 | 在 ui-minimal 之后（同样改外壳样式） |
| [11-07-multi-genre](../11-07-multi-genre/prd.md) | 多流派：迁移、扫描、接口、前端显示与修改 | 后端和 ui-minimal 并行；前端在 ui-minimal 之后 |
| [11-07-duplicate-artist-rules](../11-07-duplicate-artist-rules/prd.md) | 删除错误规则并清理、新增括号别名规则、新理由文案 | 后端和 ui-minimal 并行；理由文案在 ui-minimal 之后；页面改名由 sidebar-my-music 负责 |
| [11-07-library-dir-browser](../11-07-library-dir-browser/prd.md) | 目录列表接口、添加目录时的浏览器 | 后端和 ui-minimal 并行；前端在 ui-minimal 之后 |

前后端都要改的子任务（multi-genre、duplicate-artist-rules、library-dir-browser）：
1. 先由 Opus 子 agent 起草接口合同和 `design.md`，主会话审阅、裁决（2026-11-07 已完成）；
2. 再派后端和前端；
3. 后端、前端和接口样本放在同一个提交里。

执行顺序和收尾见 [执行计划](implement.md)。
