# 真实库 ALAC 派生核对（只读汇总）

核对日期：2026-10-10。按[真实音乐资产规范](../../../../../spec/guides/real-music-assets.md)只读执行，只记录汇总计数与耗时，
不记录路径、文件名或内容，没有保存任何派生文件。

## 方法

- 用一个**没有提交**的临时 Go 测试（运行后已删除），在 `derivation` 包内驱动服务端实际使用的 `FFmpeg.Convert`：
  固定参数数组的两遍转换，输入强制按 ALAC 解码，第一遍同时输出 FLAC 与源解码后 PCM（`pcm_s32le`）的 MD5，
  核对输出的 `STREAMINFO`（位深、采样率、声道与解析器读到的文件事实一致、总样本数大于 0）与是否触及大小上限，
  第二遍解码输出再取 MD5，两遍摘要必须相同。
- 遍历 `music/` 下全部 `.m4a`，逐个以只读方式打开；输出写到临时目录并在核对后立即删除。输出上限与服务端相同（源大小 × 2 + 16 MiB）。
- ffmpeg 是 `scripts/ffmpeg-pinned.sh` 取出的固定版本 7.1.1（静态构建）；本机 12 核虚拟机，单线程转换，逐个顺序执行。
- 范围限制：这验证的是转换与核对本身，不经过 HTTP、数据库与缓存管理；预期的位深、采样率与声道取自解析器对文件的读取，
  与扫描记录同源，没有读取用户的数据库。

## 结果

| 类别（解析器读到的事实） | 成功 | 失败 |
| --- | --- | --- |
| ALAC 24 bit / 48 kHz / 2 声道 | 73 | 0 |
| ALAC 16 bit / 44.1 kHz / 2 声道 | 10 | 0 |
| ALAC 24 bit / 44.1 kHz / 2 声道 | 1 | 0 |
| **合计（84 个 `.m4a`）** | **84** | **0** |

- 无法解析或无法读取的文件：0。
- 源合计 3127.5 MiB，FLAC 输出合计 3044.8 MiB（约为源的 97.4%）。
- 全部 84 个耗时 98.7 秒（含两遍核对）；单个文件最短 0.09 秒、中位 1.22 秒、最长 3.29 秒。
  中位数对应约一首 5 分钟曲目的首播等待，低于 20 秒的预检长轮询。

## 结论与未覆盖的部分

- 真实库的 84 个 ALAC 都能无损转换，并且转换前后解码出的 PCM 逐位相同；没有失败类别，也没有触及输出上限。
- 这不证明浏览器对这些具体 FLAC 的实际解码与听感，也没有覆盖服务端的缓存、等待者与撤销路径（它们由集成测试与真实服务自动化覆盖）。
  最终确认需要用户在宿主机装好 ffmpeg、重启服务后播放几首 ALAC（见 PRD 的“实施结果”）。
