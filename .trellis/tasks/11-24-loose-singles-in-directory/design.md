# 设计：同一目录里的零散单曲不归成一张专辑

## 现状

- 子目录的整理范围是整个目录（`catalog/ingest/scope.go` 的 `OrganizationScope`）。没有一个文件带真实专辑标签时，专辑分区全是 `"|"`（推断值不参与分区，`organizer.go` 的 `albumPartition`），
  整个目录成为一个 `ordinary_directory` 候选，标题退回解析器推断的目录名（`library/parser/tags.go` 的 `applyFilenameFallback`，来源 `folder_fallback`）。
- 根目录下没有专辑的文件：扫描器清掉推断的专辑，每个文件一个 `loose_unknown` 候选（分区是路径），标题 `未知专辑`；内嵌封面按路径区分（`artworkScope`）。
- 自动整理只在 `candidate_kind == loose_unknown` 且只有 1 首时走单曲模式（`curation/program/match_lookup.go`），ISRC 与声学指纹的单曲判定都在这条路上。
- 内嵌封面按 `目录 + 专辑 + 格式` 去重，`Singles/` 这类目录里除第一首外的内嵌封面在暂存时就被丢弃（`ingest/staging.go`）。

## 决定

### 1. 判定规则（零散单曲目录）

一个子目录（按格式拆分之后的同一格式组）里的文件，**全部**满足下面各条时，每个文件各成一个 `loose_unknown` 发行；任何一条不满足，按现状归成一个发行：

1. 没有真实专辑标签（专辑只有推断值）；
2. 标题与艺人都来自标签，不是推断值（不来自文件名、目录名或 `未知艺术家` 的兜底）；
3. 没有曲序：曲序标签与文件名推出的编号（`prepareFilenameEvidence`）要么都没有，要么所有文件相同（流媒体单曲常是全为 1）；只要出现两个不同的编号，就当作专辑；
4. 目录名没有被识别为专辑（`parseFolderMetadata` 没有匹配到专辑格式，例如 `2001 - 范特西`）；
5. 不是多碟目录、盒装叶子目录，也不在已有的同目录拆分（`same_dir_split`）、CUE 规则之内。

只有一个文件的目录同样适用。

理由：没有标签的整张专辑（V12 的《U87》）不满足第 2 条；带曲序的专辑不满足第 3 条；目录名写明专辑的不满足第 4 条。
剩下“有标题和艺人、没有专辑、没有曲序”的文件，最合理的解释是各自独立的单曲，与根目录散曲的处理一致。艺人是否相同不作为条件：同一艺人的单曲合集目录同样应拆开。

### 2. 候选与标题

- 类型沿用 `loose_unknown`，锚点的 `Scope` 仍是目录，分区用 `"source:" + 路径`（与 `stableAnchorPartition` 对非常规类型的取法一致，实现时核对），
  不新增类型，前端标签、`normalizeCandidateKind`、自动整理的单曲模式都不用改。
- 标题与根目录散曲一致（推断的目录名不作标题）。

### 3. 内嵌封面

`artworkScope` 对“没有专辑证据、标题与艺人都来自标签”的子目录文件按路径区分，让拆开后的每个单曲保留自己的内嵌封面。
这只看单个文件，可能让少数仍归成一张专辑的文件多存几份内嵌封面；发行显示的封面按既有优先级选择，不应变化，由既有封面测试把关。
`loose_*` 候选不取目录封面，沿用现状（一个 `Singles/cover.jpg` 不属于任何单曲）。

### 4. 版本与 ID

- `ingest.GroupingVersion` 加一，按 `.trellis/spec/backend/library-scan-incremental.md` 的规则让增量扫描重新归组没有变化的目录。
- 已存在的“目录名专辑”重扫后拆开：按现有分配规则，键最小的那个单曲保留旧发行 ID，其余是新发行与新专辑组。
  旧发行上的发行级修正、自动层、外部封面、收藏（按组）留在保留 ID 的单曲上；曲目 ID 不变，曲目级的修正与收藏不受影响。
  这与既有的“拆分保留多数一方的 ID”相同，不另做迁移。
- 与 `11-24-reopen-shelved-on-new-evidence` 的关系：拆开后保留 ID 的发行证据变了，原有的搁置项按输入摘要变化重开；新发行另建待定项（单曲模式下是 `recording_match`）。

### 5. 规范

`.trellis/spec/backend/library-scan-grouping.md` 的同目录规则与封面分层补上第 1–3 节；`curation-contracts.md` 不变（单曲模式仍只看 `loose_unknown`）。

## 不做

- 不改根目录散曲的行为与标题。
- 不用外部源结果决定归组。
- 不为零散单曲新增候选类型或界面。
