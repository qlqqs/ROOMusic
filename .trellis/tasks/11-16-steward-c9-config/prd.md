# 管家 C9：应用配置与诊断工具

## 目标

管理员可以让管家查看实例的运行状况，并代为调整应用内的配置：音乐目录、扫描、成员、备份；
每个用户可以让管家调整自己的播放与音效设置（父任务 R5、R6）。

## 背景与约束

- 配置类写入现在都不经过 `operations.Run`，没有撤销：目录的添加、停用、恢复、迁移与排除规则
  （SQL 写在处理函数里，`library/httpapi/roots.go:72`、`root_operations.go`、`exclusions.go:24`，有自己的
  `library_root_operations` 记录）；扫描的启动与取消、扫描计划（`library.Service`）；成员的新建、停用与启用、
  重置密码、吊销会话（`identity/httpapi/handlers.go`，SQL 在处理函数里）；手动备份、删除备份、保留策略（`backup.Service`）。
  没有改成员角色的接口；恢复备份只有命令行。
- 个人设置：分区的播放与音效设置走 `zones.Service.Command` 的 `set_settings`；PEQ 预设在 `dspsettings`。
- 诊断现状：日志只写标准输出，没有应用内读取；没有磁盘占用；不使用 ffprobe（ADR 0004），曲目的音频信息来自
  已存的音频事实、`playback.Service.Prepare` 与响度分析；`/readyz` 只检查连接句柄；版本接口仅管理员。
- 产品合同：不提供 `run_sql`、`run_shell`、`operate_path`（`agent-and-operation-guidelines.md:118-120`）。
- ADR 0005：密钥、令牌、数据库连接串、环境变量不发给模型；日志与诊断发给模型前按日志规范脱敏，路径只留相对部分。

## 决定

| 编号 | 日期 | 选择者 | 决定 |
| --- | --- | --- | --- |
| D1 | 2026-11-16 | qlqq | 只做具名诊断工具，不做只读 SQL |
| D2 | 2026-11-16 | qlqq | 配置类写入标为不可撤销，照常进确认方案；重置密码、删除备份、删除成员数据不交给管家 |
| D3 | 2026-11-16 | 主代理 | 新建成员不做成工具（需要经模型传递初始密码）；目录迁移（relocate）不做成工具（影响面大，留在设置页） |
| D4 | 2026-11-16 | 主代理 | 最近日志：进程内保留最近 1000 条已脱敏的日志记录，仅管理员可读，重启后清空 |
| D5 | 2026-11-16 | 主代理 | 添加目录时路径仍由后端的 `library.ValidatePath` 与允许的根目录校验；工具输出里的路径按 ADR 只给相对部分 |

## 需求

- R1 诊断工具（read，管理员）：系统状态（版本、运行时长、数据库连通与连接池、迁移版本、曲库统计）；
  磁盘占用（数据目录、备份目录、各音乐目录所在文件系统的总量与可用量）；最近日志（按级别、模块、时间过滤）；
  备份概况；音频分析进度。
- R2 曲目音频信息（read，成员）：格式、采样率、位深、时长、文件大小、响度分析结果。
- R3 配置工具（shared，管理员，不可撤销）：添加目录、停用与恢复目录、添加与移除排除规则、启动与取消扫描、
  保存扫描计划、停用与启用成员、吊销成员的会话、发起手动备份、保存备份保留策略。
- R4 只读工具（管理员）：目录与排除规则列表、扫描计划、成员列表（不含密码哈希与会话）、保留策略。
- R5 个人设置工具（personal）：读取与修改自己分区的播放与音效设置；列出与应用自己的 PEQ 预设。
- R6 配置工具在确认卡片上显示旧值与新值（有的话）并标明不能撤销；`steward` 模式下按 C7 的策略一律转人工确认。
- R7 目录相关的写入从处理函数里抽到 `library` 包的服务方法，HTTP 接口与工具调用同一个方法，行为不变。
  成员的停用、启用、吊销会话同样抽到 `identity` 包。
- R8 这些写入留下可查的记录：目录操作沿用 `library_root_operations`；其余写入记一条带来源的结构化日志事件。

## 验收

- A1 问“磁盘还剩多少”“最近有没有报错”“数据库正常吗”，管理员得到基于工具结果的回答；成员得到没有权限的说明。
- A2 日志工具的输出里没有密钥、令牌、连接串、消息正文和绝对路径（用含这些内容的合成日志核对）。
- A3 “每天凌晨三点扫描”“把 X 目录加进来然后扫一遍”：出现确认卡片并标明不可撤销，确认后生效，设置页能看到。
- A4 添加允许范围之外的路径被后端拒绝。
- A5 停用最后一个管理员被拒绝；管家不能重置密码、删除备份、新建成员（没有这些工具）。
- A6 成员在任何模式下调不到配置工具；能调整自己的音效设置，且只影响自己。
- A7 抽取之后目录、成员的现有 HTTP 接口用例仍然通过。

## 不做

- 只读 SQL（D1）；重置密码、删除备份、新建成员、目录迁移、恢复备份（D2、D3）。
- 给配置写入补操作记录与撤销；环境变量类的实例设置；设备改名与删除、IR 文件上传。

## 规划结论

路线：用户选择。qlqq 于 2026-11-16 要求 C5–C11 一次规划完后直接执行，不逐个子任务再问；
标“主代理”的决定按建议取值，用户验收时可以改。
