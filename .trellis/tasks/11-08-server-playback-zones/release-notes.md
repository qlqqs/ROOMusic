# v0.5.0 发版说明（草稿）

## 播放改由服务器统一处理

- **队列不再随标签页丢失**：队列、当前曲目、位置和播放设置都保存在服务器上，关掉页面或重启服务后都还在。升级后第一次打开页面时，浏览器里现有的队列会自动导入。
- **一台设备控制另一台**：每个浏览器是一台设备，各放各的。在任一设备上都能查看和控制自己账号下的所有设备，也能把正在放的内容整体转到另一台设备，从原位置接着放。
  正在出声的设备离线（关页面、断网）后会暂停，可以一键转到手上这台继续听。同一浏览器的多个标签页只有一个出声。
- **曲间默认无缝**：同一张专辑的相邻曲目之间没有停顿，也可以改用交叉渐变。
- **电平化、Headroom 与信号路径**：电平化改在服务器上进行。新增 Headroom 设置，默认关闭，开启后可以显示削波指示。信号路径会列出每一步处理，有损环节都会标出来。降低位深时加抖动。
- **省流量音质**：在外时可以在“设置 › 播放 › 音质”里选“省流量”。
- **格式**：整轨加 CUE 的分轨曲目可以播放，相邻两轨衔接无缝。ALAC、APE、WavPack、AIFF 都由服务器实时解码，不再需要预先转换。
- **iPhone / iPad**：锁屏后可以连续播放，跨格式也能接上，锁屏上的曲目信息随播放切换。

## 升级注意

- 本版数据库迁移从 0042 到 0044；应用在迁移前自动备份，请保留备份与原配置。
- **反向代理需要调整**（见 `deploy/production/README.md` 第 5 节）：
  - 事件流和音频流不能缓冲；
  - 上游读超时至少 60 秒；
  - 不压缩 `text/event-stream`。
  
  否则别的设备上的播放变化会延迟很久才出现，或者放不出声。
- 升级后会自动删除旧的 ALAC 转码缓存目录。
- 降级到更早版本后，各设备的播放队列会清空；降级前的队列保留在自动备份里。
- 已知限制：iPhone 锁屏后暂停超过约 10 秒，要解锁才能继续播放。这是 iOS 对网页播放的限制。
- 旧的逐首播放接口（`GET /tracks/{id}/playback`、`/audio`、`POST /me/plays`）在本版保留，下一版删除。
