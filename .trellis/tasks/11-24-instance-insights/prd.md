# 匿名实例统计与源代码链接

父任务：`11-24-adoption-readiness`（第 1 项）。

## 目标

项目方能数出 7 天与 30 天内活跃的实例数、版本与架构分布、各功能的使用比例，用来判断手机端与模型服务值不值得做；
管理员清楚知道发送了什么，可以随时关闭。界面给出源代码地址，满足 AGPL 对网络服务的要求。

## 已定（qlqq）

- 默认开启；管理员首次登录时看到说明，列出发送的全部字段，可一键关闭；统计汇总公开。
- 统计端部署在本机，域名 `roomusic.org`；统计端程序开源在本仓库。

## 主代理取的默认值

| 项 | 默认 |
| --- | --- |
| 统计端地址 | `https://insights.roomusic.org/api/v1/heartbeat`；公开页 `https://insights.roomusic.org/` |
| 首次发送 | 实例创建满 24 小时、且已有管理员之后；给管理员留出看到说明、关闭的时间 |
| 频率 | 每 24 小时一次，加最多 1 小时的随机偏移；失败等下一轮，不密集重试 |
| 部署层关闭 | `ROOMUSIC_INSIGHTS_DISABLED=true` 强制关闭，界面开关显示为不可改并说明原因 |
| 开发版本 | 版本号为空（开发构建）时不发送，除非显式设置 `ROOMUSIC_INSIGHTS_URL`（测试与 mock 用） |
| 实例 ID | 首次启动随机生成的 UUID，与机器、IP、账号无关；关闭再打开不变 |
| 数字一律分档 | 曲目数、发行数、成员数、设备数只发分档，不发精确值 |
| 不记录 IP | 统计端只在内存里按 IP 限速，不落盘 |
| 保留期 | 统计端丢弃 90 天没有心跳的实例 |
| 源代码链接 | “设置 › 关于”（所有登录用户可见）显示许可与源代码地址，管理员另外看到版本；登录页底部也有源代码链接。地址默认 `https://github.com/qlqqs/ROOMusic`，`ROOMUSIC_SOURCE_URL` 可改，供修改版指向自己的源码 |

## 发送的字段（第 1 版）

| 字段 | 内容 |
| --- | --- |
| `schema` | 固定 `1` |
| `instance_id` | 随机 UUID |
| `version`、`os`、`arch` | 应用版本、`linux`、`amd64`/`arm64` |
| `container` | 是否在容器里运行 |
| `library.tracks`、`library.releases` | 分档：`0`、`1-999`、`1k-10k`、`10k-50k`、`50k+` |
| `members` | 启用的账号数分档：`1`、`2-5`、`6-20`、`21+` |
| `features` | 布尔：自动整理已开、配置了管家模型（实例或任一成员）、有未吊销的 MCP 令牌、局域网设备已开、有人开着参数均衡或卷积、定时扫描已开；已启用的插件数分档 |
| `devices_30d` | 30 天内用过的输出端，按类型（`browser`、`upnp`，以后加 `cast`、`airplay`）分档：`0`、`1`、`2-5`、`6+` |

不发：曲目、艺人、文件名、路径、用户名、邮箱、IP、模型地址或密钥、任何文本内容。

## 要求

1. 服务端按上述规则发送心跳；出站按公网地址规则，不跟随重定向，超时 10 秒；接入外部接口 mock。
2. 管理员接口：读取状态（开关、是否被部署层关闭、实例 ID、说明是否已确认、上次发送时间与结果、**将要发送的完整内容**）；修改开关；确认说明。
3. 前端：管理员概览顶部的说明（直到确认），可“查看发送内容”“关闭统计”“知道了”；设置里的“匿名统计”区段（开关、发送内容预览、上次发送、公开统计页链接）；“设置 › 关于”与登录页的源代码链接。
4. 统计端程序 `roomusic-insights`：接收心跳（严格校验、大小上限、按 IP 限速）、按实例去重、公开汇总接口与汇总页、90 天清理；数据存在单个文件里，原子写入；部署文件与说明放在 `deploy/insights/`。
5. 文档：新 ADR（匿名实例统计）、`docs/insights.md`（给用户看的字段说明与关闭方法）、部署说明与 README 的说明、后端合同。

## 验收

- 新实例 24 小时内不发；之后每天一次；关闭后不再发；部署层关闭时接口与界面显示不可改。
- 发出的 JSON 与管理员接口里的“将要发送的内容”逐字一致，且只含上表字段。
- 统计端拒绝格式不对、超长、多余字段的请求；同一实例多次心跳只算一个；汇总只按 7/30 天窗口计数。
- 统计端不在任何文件或日志里写 IP。
- 概览说明在确认后不再出现；关闭开关后界面立即显示已关闭。
- “设置 › 关于”和登录页能看到源代码链接；改 `ROOMUSIC_SOURCE_URL` 后链接跟着变。
- 390 与 1440 宽度截图核对新界面。

## 不做

- 统计端的实际上线（DNS、OpenResty 站点、启动容器）：需要 qlqq 授权，单列为交付后的操作。
- 崩溃报告、性能数据、按用户的使用统计。
