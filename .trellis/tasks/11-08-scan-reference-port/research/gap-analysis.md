## 2. 参考设计的核心规则（摘录，便于子任务直接引用）

### 2.1 架构

- 每个根目录一个“目录存储后端”；工作队列串行消费（并发 1），失败按 500ms → 30s → 60s… 指数退避重试；记录构造全局固定 4 并发，“扇出 + 屏障汇聚”。
- 状态载体是常驻内存的目录树缓存（目录节点只有存活标记，文件节点有时间戳和轮次号），空闲 300 秒换出磁盘。
- 增量省的是“遍历之后的处理”：每轮仍逐层列目录；文件创建/修改时间未变只盖本轮轮次号，不打开文件。
- 删除：列完一层，本轮未盖章的文件和子目录即时移除；删除事件延迟 500ms，期间对象重现则撤销。
- 归组与扫描解耦：扫描只出文件级记录；归组带算法版本号，组内成员、归组标识和附属文件都没变就整组跳过，升版本即全量重算。
- 单文件失败只生成“跳过记录 + 原因码”（IO 失败/格式不支持/文件损坏/不存在/外部解码失败/标签抽取失败/图片载入失败/类型不支持/未预期错误），不中断批次；单目录列举失败进重试队列。

### 2.2 文件规则

1. 路径过滤（14 章）：强制忽略（哈希缓存、自身备份、系统卷信息、NAS 缩略图目录）、默认忽略（临时目录、路径含 `/.`、备份工具元数据、快照）、用户配置；构造期一次归一化为小写正斜杠，从根之后做子串匹配；回收站需多个特征目录同时存在才忽略。目录被忽略只跳过本层文件，子目录到下一层再判。
2. 类型：扩展名白名单（大小写不敏感、定长后缀比较）决定“是否尝试”；构造记录时内容嗅探决定“是否成立”（JPEG `FF D8`、PNG 8 字节签名；音频由原生层嗅探并校验流参数白名单）。
3. 差异比对（6.6）：缓存未命中 → 新增；创建或修改时间变化 → 修改（降精度：任一侧整秒则两侧降到秒，再看整十）；时间戳未变但上轮读失败 → 重试；都没变 → 只盖章；路径字节不同但 Unicode 规范化后等价 → 补录，不算修改。
4. 标识：资源标识 = 相对根路径（正斜杠）；曲目身份 = 音频流摘要 → 文件结构摘要 → 头/中/尾各 32KB + 文件长度的三点采样摘要。
5. 路径比较：两侧规范化为 NFD；大小写敏感性启动时探测，探测不出默认不敏感。
6. 封面文件：基名（去扩展名、小写）等于 `cover`/`folder` 或包含 `front`。

### 2.3 文件夹名与文件名规则

归组目录（12.1）：

```
父目录名能解析出碟号 → 余量为空则上提到祖父目录；余量非空则为 祖父目录/余量
附属文件且父目录名 ∈ {art, artwork, scans, extras}（小写比较）→ 上提到祖父目录
其余 → 父目录
```

碟号解析（12.2）：

- 标题正则 `(?:[(<\[{]|\b)(?i:disc|disk|cd)[\s-]*([\w\-]+)(?:[)>\]}]|\b)`；名字里不含 disc/disk/cd 直接失败。
- 捕获全为数字 → 整数；全为字母或连字符 → 先按英文数字词（`two` → 2），再按罗马数字（`IV` → 4）。
- 归一化名 = 去掉匹配片段后的余量：匹配在开头时只移除匹配片段，否则从匹配处截断到结尾。
- “裸数字”开关在归组链路关闭：`1/`、`2/` 不当碟目录。

实例（13.5）：`专/CD1`、`专/Disc 2`、`专/Cd3` → `专`；`专/CD 1 Bonus` → `专/Bonus`；`专/Album CD1` → `艺/Album`；`专/Scans/封.jpg` → `专`。

文件名推断碟号/轨号（12.2，五级，先命中先用）：

1. 文件名本身是 1–2 位纯数字 → 轨号。碟号同时从所在目录名用上面的碟号解析取得。
2. 路径正则 `^\s*(?:(\d{1,2})[\s_\-\.]+)?(\d{1,2})(?:\D.*)?$`：`1-03 Song`、`02 03 Song`、`2.03 Song`、`1_02_track`；第 1 组作碟号（碟号未定时），第 2 组作轨号；0 归空。
3. 前导数字位数（跳过前导空白）：3 位 → 1 位碟 + 2 位轨（`103`）；4 位 → 2 + 2（`0103`）。
4. 文件名末尾数字：末两位是数字取两位，否则取一位；0 归空。
5. 字面 `track` 后紧跟数字：`track05`、`Track 07`；优先两位。

同目录归组决策（12.3）：分桶（用户指定 → 外部服务专辑 ID → 标签不足 → 常规），常规桶按序尝试：整目录轨号连续性检验（标签碟轨 → 文件名碟轨 → 混合 → 只认文件名轨号且不允许缺碟）→ 按音频格式切分后再检验 → 专辑名规范化键共识（需全员有专辑名）→ 艺人 + 专辑名。

兜底名（13.6）：标签无专辑名时取归组键最后两段合成 `艺 - 专`，并标“名称非真实值”；根目录文件得空串（缺陷）。

合并键（12.7）：标点和符号变空格 → 小写 → 丢弃空白 → 变音符号折叠到基字符 → 连字展开。

专辑名碟号剥离（21.12）：同一碟号解析器作用于专辑名，剥离 `(Disc 2)`、`CD1` 等标记后再参与归组。

## 3. ROOMusic 现状（2026-11-08，`B/` = `backend/internal/`）

### 3.1 架构与调用链

1. `POST /api/v1/scans`（`B/library/httpapi/scans.go:12-34`）→ `StartScan`（`B/library/scans.go:309-372`）：进程内 `scanMutex` + `pg_try_advisory_lock(class, hashtext(current_schema()))`；遗留 running 改为 incomplete（`process_restarted`）。
2. `runScan`（`B/library/scanner.go:94-183`）：每 500ms 轮询持久化取消；`countScanRoots` 预计数再走一遍目录树（`B/library/scan_progress.go:200-269`）；根目录逐个串行。
3. `scanRoot`（`B/library/scanner.go:280-546`）：清 staging → `registeredRootAvailable`（遍历前、整理前、保存前各一次，`:678-689`）→ WalkDir 遍历，每个文件同步 `ParseAudioFile` 后写 `scan_observations` → `AlignCueStagingScopes` → `PlanStagedRoot` 身份规划（`B/catalog/ingest/identity_plan.go:72-117`）→ `persistStagedCandidates` 每候选一个短事务（`B/library/scanner.go:724-769`）→ 封面。
4. `finalizeScan`（`B/library/scanner.go:217-261`）：只有 `succeeded` 才把 `observed_at < started_at` 的曲目标 missing（`B/catalog/ingest/persist.go:283-290`，`scan_feedback_missing.go:12-77`）。
5. 并发：每 schema 一个扫描；根、文件、指纹、候选全部串行；整个扫描一条数据库连接。
6. 失败传递：任何单文件问题 → `complete=false` → 根 incomplete → 扫描 incomplete；诊断每次最多 100 条（`B/library/scanner.go:1062-1065`）。
7. 没有文件监听、没有定时扫描（go.mod 无 fsnotify）。

### 3.2 文件处理（`B/library/scanner.go:318-481`）

1. WalkDir 深度优先、目录内字节序；目录链接 SkipDir。
2. **没有路径过滤**（已核实）：`.xxx`、`._x.flac`、`@eaDir`、`#recycle` 照常进入；只有目录浏览接口过滤 `.` 开头（`B/library/folders.go:60`）。
3. 任何符号链接先 EvalSymlinks，断链或越界记 `broken_or_escaped_link` 并标不完整，且排在扩展名过滤之前（`:339-348`）——断掉的 `cover.jpg` 链接也会让扫描不完整。
4. 扩展名 `ToLower(filepath.Ext)`：支持 `.flac .mp3 .ogg .opus .wav .m4a`（`:927-934`）；候选 `.aac .aif .aiff .ape .dff .dsf .m4a .mka .wma`（`:936-943`）→ `unsupported_format` + 标不完整（已核实 `:447-452`）；`.cue`；其余静默忽略。
5. `ParseAudioFile` 失败 → `parse_failure` + 标不完整（已核实 `:454-460`）。`._x.flac` 必然走到这里。
6. 每次重扫对每个文件都解析（`:454`）；只有内容指纹在来源身份匹配且 size、mtime 都相等时复用（`B/catalog/ingest/identity_plan.go:167-179`）。目录改名后来源身份变了，指纹全部重算。
7. 相对路径只 `ToSlash` + `path.Clean` + 去首尾空白（`B/library/scanner.go:59-66`、`B/catalog/ingest/paths.go:10-16`），无 NFC/NFD；CUE `FILE` 引用按字节匹配，NFC/NFD 或大小写不符即 missing（`B/library/parser/cue_path.go:36,77`）。
8. 非音频：封面固定名单 `cover.{jpg,jpeg,png,webp}`、`folder.{jpg,jpeg,png}`、`front.{jpg,jpeg,png}`，名字精确匹配、大小写不敏感（`B/library/scanner.go:989-1060`）；`.log` 读前 64KiB 认 EAC/XLD 签名（`:777-878`）。
9. OGG/Opus 解析整文件读入内存（已核实 `B/library/parser/ogg.go:15`）。

### 3.3 文件夹名与文件名

1. 碟目录识别（已核实 `B/catalog/ingest/organizer.go:272-293`）：目录名最后一段小写后**必须以** `disc`/`cd`/`disk` 开头，`TrimLeft(" _-.([")` 后取前导数字（>0），剩余 `Trim("_-.()[]")` 后必须为空。认 `CD1`、`cd 01`、`Disc.2`、`DISK_3`、`CD(1)`；不认 `Disc One`、罗马数字、`Disc 1 - 副标题`、`CD1 Bonus`、`Disc 1 of 2`、`[Disc 1]`、`Album CD1`、纯数字。
2. scope（已核实 `B/catalog/ingest/scope.go:9-22`）：碟目录 → `disc-parent:<父>`；根目录 → 有权威专辑时 `root-album:<sha256 前 12 字节>`，否则 `root-source:<路径>`；其余 `directory:<目录>`。**分组只在 scope 内进行**，未被识别的碟目录各成一个 scope，同名专辑会成为多张 Release。
3. 严格多碟（`organizer.go:455-483`）：碟号 ≥2 种、兼容 partition ≤1 种、每碟号一个目录、1..max 齐全，才上提为 `strict_multidisc`；否则每碟一个 `box_leaf`。
4. 兜底（已核实 `B/library/parser/tags.go:126-152`）：无标题 → 去扩展名的文件名（不去前导轨号）；无艺人 → “未知艺术家”；无专辑 → 父目录名（inferred）；轨号/碟号 ≤0 → 1（inferred）。根目录文件清空专辑兜底（`B/library/scanner.go:467-469`）；严格多碟无权威专辑时用父目录名（`organizer.go:615-618`）；box_leaf 无标签时专辑名就是 `CD1` 之类。
5. 补位（`organizer.go:655-721`）：inferred 轨号按 `路径\0标题\0专辑\0艺人` 字节序补最小未占用号，`1, 10, 2` 会排错。不从文件名推断任何编号。
6. folder_metadata（`B/catalog/ingest/folder_metadata.go:48-233`）：比参考设计强——认 EAC、JP-PT、JP-PT-Dash、Date-Title、WEB-DL、DIC、Bracket-Suffix、`艺人 - 专辑 (年份)` 共 8 种，抽日期、唱片编号、媒介、位深、格式、edition、label。
7. 合并键：`albumPartition = NormalizeValue(album)|NormalizeValue(albumArtist)`，只压空白、区分大小写（`organizer.go:295-308`、`B/catalog/metadata/text.go:20-22`）。
8. 同目录多专辑：非 `|` partition 种类 ≤1 或赢家过半 → 一个候选；否则 `same_dir_split`（`organizer.go` 分组段）。没有轨号连续性检验，没有按格式切分。
9. 专辑名里的 `(Disc 2)`/`CD1` 不剥离，碟目录专辑名不同会让严格多碟失败（`organizer.go:457`）。

### 3.4 相关的其它事实

- 空挂载：根目录存在但为空时遍历成功，整库被标 missing；下次正常扫描按来源身份恢复 present、ID 不变（`B/catalog/ingest/persist_track.go:81`），不丢数据。
- 没有 present 曲目的 Release 在读取侧隐藏（`B/catalog/read.go:188`）；空 media 在候选写入时删除（`B/catalog/ingest/persist.go:120`）。规则变化导致重新归组时，落选的旧 Release 会变成隐藏空壳。
- 前端诊断类别中文名表（`frontend/src/features/library/diagnostic-kinds.ts:5-28`），未知类别原样显示。
- Release 身份按“严格过半沿用”（`B/catalog/ingest/identity_plan.go:357-397`），候选键 `root:v2:kind:scope:partition` 只作定位（`organizer.go:1069-1072`）。

| G10 | 解析与指纹 4 路并发，单写入者 | 7.1 | 首扫与重扫全串行 |

### 不复刻

- 专辑 ID 用成员集合摘要生成（加减一首就换 ID，与 Release 严格过半沿用冲突）。
- 三点采样直接替换现有指纹（头块含标签，破坏“身份与标签无关”）。
- 只要识别出碟号就上提、不做校验；根目录散文件全部归一组；`艺 - 专` 合成兜底名（folder_metadata 更准）。
- 子串式忽略规则（文档自认会误杀）；大小写敏感自动探测（ext4 上默认不敏感会误合并）。
- 逐目录即时删除、列举失败以空集合继续（不完整读取会放大为删除）。
- 降精度时间戳比较（ROOMusic 只有一个读 mtime 的入口）。
- 实时文件监听（NAS/网络挂载不可靠、句柄上限）；内存目录树缓存与换出（状态在 PostgreSQL）。
- 外部资料库编目导入、列表文件、SMB 挂载、卷管理、导入整理、事务式写入、云存储、设备协议、DSP（只读库或不在扫描范围）。
- 标签/署名/古典/流派/搜索（第 21–24 章）与音频分析扩充：不属于本次“扫描架构与文件/文件夹规则”的范围，是否纳入待用户裁决。
