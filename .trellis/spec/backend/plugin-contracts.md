# 数据源插件合同

公共 ABI、清单格式和管理员接口见[插件开发说明](../../../docs/plugins.md)。运行时类型仅允许出现在 `backend/internal/plugins/runtime`；来宾示例为独立 Go 模块。插件依赖宿主提供的外部源接口，业务写入由整理程序负责。

## 运行模式与资源

2026-11-24 在 Linux amd64 的 ROOMusic 生产运行镜像中，以 UID/GID 1000、只读根、全部丢弃 capabilities、no-new-privileges 和禁网运行静态 Go 探针。显式选择 wazero v1.12.0 编译器，调用 Extism v1.7.1 的最小计数模块，输入 hello，退出码 0，计数为 2。编译产物写入挂载数据目录的 `plugins/.cache/wazero-v1.12.0-amd64-linux/`。部署沿用已有数据卷。启动时记录实际模式，编译器不可用时使用解释器。

每次调用新建实例，共用编译缓存。一个插件最多两次并发，预检与已安装版本按同一个插件标识计数。10 秒预算包含候用时间。来宾和 Extism 交换区各限 512 个 64 KiB 页，合计最多 64 MiB 线性内存。WASI 只接入系统时钟和随机源，文件系统无预打开目录，环境、套接字配置为空。保持 AllowedHosts、AllowedPaths 为空。设置了会向进程标准输出透传日志的 EXTISM_ENABLE_WASI_OUTPUT 时，宿主拒绝初始化。

## 上游与数据

每个已确认上游有独立的 Requester、限速器和缓存命名空间。只拼接经检查的路径与查询，拒绝目录穿越、绝对地址及重定向。通常用 PublicOnly，仅配置的 mock 主机和端口可额外放行，替换前缀为 `/plugins/<插件>/<上游>`。密钥在真实请求前取出并注入，公开缓存键只含方法、公开地址与 Accept。返回头只开放 Content-Type。检测到响应回显当前密钥时拒绝该响应。插件 mock 请求记录隐藏查询参数值。插件调用中止、超时或无效输出均不能打开新的写入路径。

## 安装、启停与回退

迁移 0071 记录清单、能力、包 SHA-256、两个文件各自的 SHA-256、安装时间和停用原因。哈希比较与实际调用使用同一份模块字节。预检暂存于数据目录下的 `plugins/.preview`；升级和卸载串行执行，通过目录重命名和数据库事务替换安装。外部源的开关是启用状态的唯一存储。安装、重新确认和删除均清除旧版本的开关、密钥，不删除历史操作。降级时清除旧版无法表示的插件资料、配置和密钥，再恢复旧约束，内置来源资料与操作历史保留。

`hash_changed` 需要重新预检确认；直接开源返回 HTTP 409。源开关、每次出站的权限检查、整理写入前的检查和撤销抑制适用于全部四种能力。预检调用 describe 时不授予出网上游或密钥。
