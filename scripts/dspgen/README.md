# SRC 2s 核的自主生成

## 来源与边界

`src2s.py` 仅以 SRC 任务 design §2.3 中的数值规格为输入，以余弦基展开
对称 FIR，再求解极小化最大阻带幅度的线性规划。没有读取、复制或拟合本机
参考系数；参考资料仅允许另行进行本机指标对照，不能作为生成器输入。

## 固定工具

- 本机复现环境：CPython 3.12.3。
- NumPy **2.2.6**。
- SciPy **1.15.3**，其内置 HiGHS **1.8.0**；不安装独立的 highspy。
- 本机启动工具 uv **0.13.5**。数值工具版本同时固定在脚本元数据，并在运行时检查。

从仓库根运行（需要 `uv` 和 `gofmt`）：

```bash
uv run --python 3.12.3 scripts/dspgen/src2s.py
```

依赖只装入 uv 的隔离缓存，不改项目 Go 或前端依赖。首次需要下载固定版本的
工具包；缓存齐备之后数值计算完全离线，不访问参考数据或其他服务。

## 方法

倍率为 2、4、8、16、32、64，长度为 `19L+1`。以中心点及右半核作为
未知量，频率 `x` 以输入奈奎斯特频率归一；余弦基为
`A(x)=c[0]+2Σ c[k]cos(πkx/L)`。

- 通带 `0≤x≤0.113`：`|A(x)−1|≤0.0001`。
- 半幅约束：`A(0.4758)=0.5`。
- 阻带 `0.99≤x≤L`：`|A(x)|≤δ`，目标最小化 `δ`。
- 通带和阻带各采用半核长度 8 倍的等距网格，均含端点。
- HiGHS 的原始、对偶可行性容差均为 `1e-10`。
- 还原完整对称核后按直流和归一化；该操作使最终通带偏差上界与优化约束
  不完全相同，因此生成后用独立的密集频率网格重新核验。

规格核验采用至少 `2^20` 点、至少核长 16 倍的实数 FFT。检查通带偏差
不超过 0.002 dB、阻带衰减不低于 160 dB、半幅点偏移不超过 0.002。
同时报告首次越过 −3、−6、−160 dB 的频率，便于检查过渡带。
半幅点是 −6.0206 dB，不与严格的 −6 dB 首次交点混同。

六组全部求解并通过规格检查后才写出
`backend/internal/dsp/src/kernels2s_gen.go`，只存中心向右的半核，使用
17 位有效数字保存 float64；文件头记录工具，逐组注释记录指标。
CI 不重新求解优化问题；独立测试检查入库产物性质。最小相位转换由 SRC
运行时负责，不在本生成器中产出或存储。
